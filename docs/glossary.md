# 專為藝術家與創作者打造的 Griptape Nodes 術語表 {: #griptape-nodes-glossary-for-artists-creators }

## 什麼是 Griptape Nodes？ {: #what-is-griptape-nodes }

Griptape Nodes 是一套讓藝術家和創作者無需深入具備技術背景，即可構建 AI 驅動專案的工具庫。您可以將 Griptape Nodes 想像為一組積木模組，透過將它們連接在一起，即可創作藝術作品、生成圖像、處理文字，甚至是構建以工作流程為核心的其他應用程式。

### Griptape Nodes 核心概念 {: #core-griptape-nodes-concepts }

- **工作流程 (Workflow)**：包含節點、連線和參數數值的文檔。雖然從技術層面來說工作流程也是一種指令碼 (Script)，但請避免將其稱為「指令碼」，以使「指令碼」一詞能夠與「工作流程」清晰區分。這也是我們對已儲存檔案的統稱。
- **工作流程編輯器 (Workflow Editor)**：用於添加、連接和設定節點的工作區畫布。
- **流 (Flow)**：構成一個功能單元的一組相互連接的節點。一個工作流程可以包含 0 到多個流。
- **子流 (Sub-Flow)**：在循環 (Loop)、分支 (Branch)、引用 (Reference)（有時包括分組）內部執行的自包含節點集合。指作為一個凝聚單元運行的任何邏輯上獨立、內部自包含的流區塊。
- **引用 (Reference)**：指向另一個流的連結，將其作為子流嵌入當前上下文中。
- **分組 (Group)**：節點的視覺化聚合。如果一個分組作為一個整體被執行，它可以作為子流；但單純的分組並不隱含執行邏輯，可能僅僅是一組在概念上相關聯的節點。
- **指令碼 (Script)**：運行程式碼的 Python 指令碼。在描述工作流程時應避免使用此詞；相反，指令碼是指工具、巨集或流構建輔助功能。
- **節點程式庫 (Libraries)**：擴展系統功能的節點定義或指令碼集合。有關安裝和管理它們的說明，請參閱[節點程式庫 (Libraries)](guides/libraries.md)。
- **節點 (Node)**：工作流程中拼圖的基本單元。節點就像樂高積木，您可以將它們連接起來拼裝出更龐大的系統。每個節點負責執行一項特定任務（例如生成圖像或處理文字）。節點主要分為以下**類型**：
    - **DataNode (資料節點)**：處理資訊的節點 — 它可以將資料從一種形式轉換為另一種形式，或單純保存您設定的資料。
    - **ControlNode (控制節點)**：負責「執行具體任務」的節點。控制節點的運行時間通常比資料節點長，因為它們通常承擔更繁重的運算工作。
    - **DriverNode (驅動節點)**：將您的專案連接到外部服務（如圖像生成器或搜尋引擎）的節點。
- **工具 (Tool)**：執行特定任務的現成組件。工具就像您數位工具箱中的畫筆 — 每一種都為特定目的而設計。
    - **CalculatorTool**：為您進行數學運算。
    - **DateTimeTool**：處理日期與時間。
    - **FileManagerTool**：協助管理檔案（儲存、載入等）。
    - **WebScraperTool**：從網站抓取蒐集資訊。
    - **PromptSummaryTool**：生成長文字的精簡摘要。
- **驅動器 (Driver)**：您的專案與外部 AI 服務或資料庫之間的連線介面。驅動器就像轉接器，讓您的專案能夠與專用外部服務順暢通訊。
    - **PromptDriver**：與 AI 文字生成器（如 GPT 模型）進行通訊。
    - **WebSearchDriver**：連線到搜尋引擎尋找資訊。
    - **EmbeddingDriver**：將文字和概念轉換為 AI 能夠理解的數值向量形式。
    - **ImageGenerationDriver**：連線到 AI 圖像生成器（如 DALL-E）。
    - **AudioTranscriptionDriver**：將語音音訊轉錄為文字。
- **引擎 (Engine)**：處理您的創意請求的核心動力源。引擎是將輸入轉化為創意輸出的專用處理組件。
    - **RagEngine**：根據提供的參考資訊處理問題並生成解答。
    - **PromptSummaryEngine**：為長篇文字生成簡潔扼要的摘要。
    - **CsvExtractionEngine**：從電子表格類型的檔案中擷取資訊。
    - **JsonExtractionEngine**：從結構化資料檔案中擷取資訊。
- **成品 / 資產 (Artifact)**：專案執行過程中產生的內容片段，例如生成的圖像或文字。Artifact 是您創意流程的最終產出。
    - **ErrorArtifact**：當執行發生異常時的錯誤通知物件。
- **智慧體 (Agent)**：可以代表您執行任務的智慧助理，通常綜合運用多種工具。智慧體就像助手，能夠為您引導完成一系列複雜操作。
- **規則集 (Ruleset)**：控制專案行為準則的指引集合。規則集就像配方，指導您的專案在不同情境下應如何回應。
    - **規則 (Rule)**：規則集內的單條具體指令，例如「如果使用者要求生成圖像，則調用模型生成一張」。

### 節點內容與內部機制 {: #node-contents-and-activities }

- **參數 (Parameter)**：您可以在節點上調整的設定項或數值。參數就像音樂合成器上的旋鈕與滑桿 — 讓您能夠微調各項功能的運作方式。
    - **ParameterMode (參數模式)**：描述參數是用於輸入、輸出、內部使用，還是上述模式的任意組合。
    - **ParameterValue (參數值)**：參數的「內部」值（即節點內部進行計算時所使用的資料）。
    - **ParameterOutputValues (參數輸出值)**：參數的計算結果或「輸出」值（即節點執行完成後產生的結果資料）。
    - **ParameterUIOptions (參數介面選項)**：控制參數在使用者介面中如何呈現的外觀設定。
    - **連接埠 (Port)**：顯示在參數左側或右側的圓形指示點。左側連接埠表示該參數可以接受傳入連線，右側連接埠表示該參數支援向外傳出連線。
    - **引腳 (Pin)**：與「連接埠 (Port)」可互換使用。
- **預設值 (Default Value)**：在您手動修改前參數所擁有的預先設定值。這就像裝置出廠時的原廠預設設定。
- **參數驗證 (Parameter Validation)**：確保您輸入的數值符合邏輯與規範的自動檢查機制。這可以防止諸如在需要數值的位置誤填文字等低階錯誤。
- **Off-prompt**：Griptape 的獨家秘密機制，即使在使用大型語言模型 (LLM) 時，也能確保某些敏感資訊保持私密不洩漏。
- **串流模式 (Stream Mode)**：一種連續處理的即時串流模式，類似於即時視訊直播而非拍攝單張照片。
- **型別提示 (Type Hints)**：指示參數預期接受何種型別資料的標籤。這就像藝術工具箱上的標籤，提示您裡面裝的是什麼顏色的顏料。
    - **Any**：表示該參數可接受任何型別資料的型別提示。
    - **List**：表示項目集合（如顏色或形狀的陣列）的型別提示。
    - **Literal**：表示參數僅接受特定預設常數值的型別提示。
    - **Union type (聯集型別)**：表示參數可接受多種特定型別中任一種的型別提示。
- **連線 (Connection)**：允許節點之間相互通訊的連線。連線就像連接不同硬體設備的訊號纜線。

## 簡化理解的技術名詞 {: #technical-terms-made-simple }

- **資料型別 (Data Types)**：
    - **字典 (Dictionary / dict)**：一種將資訊儲存為「標籤與數值配對」的容器。字典就像井井有條的置物盒，每個物件都有唯一的標籤名稱。
    - **鍵值組 (Key-Value Pair)**：一個標籤 (鍵，Key) 與其對應資訊 (值，Value) 的配對組合。字典本質上就是一組鍵值組的集合。
    - **整數 (Integer / int)**：不帶小數點的整數，如 5、-10 或 1000。
    - **浮點數 (Float / float)**：帶有小數點的實數，如 3.14、-0.5 或 2.0。
    - **字串 (String / str)**：用引號包裹的文字內容，如 "hello"、'Python' 或 "123"。
    - **布林值 (Boolean / bool)**：僅表示 True (真) 或 False (偽) 的邏輯值。
    - **清單 (List / list)**：有序且在建立後可自由修改項目的元素集合，如 `[1, 2, 3]` 或 `["apple", "banana", "cherry"]`。
    - **元組 (Tuple / tuple)**：有序但在建立後不可修改內容的元素集合，如 `(1, 2, 3)` 或 `("red", "green", "blue")`。
    - **集合 (Set / set)**：無序且內部元素均為唯一不重複項的集合，如 `{1, 2, 3}` 或 `{"apple", "banana", "cherry"}`。
    - **空值 (None / NoneType)**：表示數值不存在或為空的特殊型別。
- **環境變數 (Environment Variable)**：類似於作業系統記錄的便利貼，用於幫助正在運行的程式獲取關鍵的全域配置資訊。
- **API 金鑰 (API Key)**：一種特殊的密鑰認證憑證，允許您的專案存取 AI 圖像生成器等外部服務。可以將其視為允許您使用特定線上服務的專屬會員通行卡。

<a id="secret-keys"></a>

- **機密金鑰 (Secret Keys)**：需要嚴格妥善保管但特定操作必需的私有憑證，例如 API Token、密碼和存取金鑰。
- **機密管理器 (Secrets Manager)**：實際負責管理和防護您的機密金鑰的系統機制，確保機密資訊*絕不*外洩。

<a id="configuration-settings"></a>

- **組態設定 (Configuration Settings)**：控制 Griptape Nodes 引擎及其各組件如何運作的參數與選項集合。

<a id="project-files"></a>

- **專案檔案 (Project Files)**：構成一個 Griptape 專案的所有文檔、指令碼與相關資源檔案。

<a id="generated-assets"></a>

- **生成資產 (Generated Assets)**：Griptape Nodes 引擎在執行期間生成的檔案與資料產出，例如圖像輸出、報告或視覺化圖表。

<a id=".env"></a>

- **.env**：一種專門用於存放環境變數的特殊文字設定檔，特別適用於存放 API 金鑰等敏感機密。

## 創作者必備 AI 術語 {: #ai-terms-for-artists }

- **溫度調節 (Temperature Control)**：控制 AI 回應是更具創意發散性還是更具可預測確定性的設定項。數值越低，回應越具規律與確定性；數值越高，回應越具多樣性與創意空間。
- **嵌入模型 (Embedding Model)**：將文字、圖像或其他內容轉換為捕捉其語意本質的數值向量的 AI 工具。這能幫助 AI 深刻理解不同概念之間的關聯性。
- **LLM (大型語言模型 / Large Language Model)**：在海量文字資料集上預先訓練的 AI 系統，具備理解和生成類人自然語言的能力。LLM 能夠撰寫文章、回答問題、摘要提煉資訊，甚至構思創意內容。
- **NLP (自然語言處理 / Natural Language Processing)**：專注於讓電腦理解、解析和生成人類日常語言的 AI 領域。
- **提示詞 (Prompt)**：您提供給 AI 模型以引導其輸出的輸入文字。對於藝術家而言，這非常類似於創意簡報或給予合作夥伴的創作指引。
- **向量資料庫 (Vector Store)**：一種專門的資料庫，儲存資訊時不僅保存內容本身，還能捕捉並檢索資料深層的關聯與語意結構。
- **擴散模型 (Diffusion Models)**：透過文字描述逐步將隨機噪點引導轉換為細緻視覺畫面的 AI 生成圖像系統。廣為人知的代表包括 Stable Diffusion 和 Midjourney。
- **文生圖 (Text-to-Image Generation)**：根據輸入的書面文字描述自動生成圖像的技術，允許藝術家透過純文字提示詞將概念直接視覺化。
- **風格遷移 (Style Transfer)**：將一張圖像的視覺風格（如某幅傳世名畫的筆觸）應用轉移至另一張圖像實體內容上的 AI 技術。
- **局部重繪與擴圖 (Inpainting / Outpainting)**：能夠根據周圍畫面的上下文補全圖像缺失部分 (Inpainting)，或將畫面邊界向外自然延伸拓展 (Outpainting) 的實用工具。
- **微調 (Fine-tuning)**：對預訓練 AI 模型進行二次訓練，使其專門識別並生成特定藝術風格、指定人物主題或獨特視覺元素的調優過程。
- **潛在空間 (Latent Space)**：AI 模型在內部組織和理解概念的抽象高維數學空間；創作者可以探索這一空間，尋找不同構想之間的創意變形與漸變過渡。
- **權杖 (Tokens)**：AI 語言模型處理文字的基本切分單元，類似於單字或詞彙片段。瞭解 Token 數量限制有助於創作者精簡而高效地編寫提示詞。
- **多模態 AI (Multimodal AI)**：能夠同時理解與處理多種不同內容形式（文字、圖像、音訊）的先進 AI 系統，支援高度整合的全方位創意工作流程。
- **LoRA (低秩適應 / Low-Rank Adaptation)**：一種讓藝術家無需耗費巨額運算資源，即可在特定藝術風格上高效調校並客製化 AI 模型的小型微調技術。
- **取樣方法 (Sampling Methods)**：控制 AI 步進生成圖像的數學演算法（如 DDIM、Euler 等），直接影響畫面細節的清晰度、豐富度與結構穩定性。

## 實用程式設計概念 {: #helpful-programming-concepts }

- **回呼 (Callback)**：當特定事件觸發時自動執行的特定函式。這就像設定相機在感測到前方有動態移動時自動按下快門拍照。
- **自訂參數型別 (Custom Parameter Types)**：您可以根據具體專案需求自訂定義的特殊設定規格。
- **例外處理 (Exception Handling)**：您的專案應對運行錯誤的防禦機制。這就像在遇到突發意外狀況時啟動備用應急方案。
    - **Authentication Error (認證錯誤)**：當您的專案無法向第三方服務出示合法有效權限證明時拋出的錯誤。
    - **KeyError (鍵錯誤)**：當您的專案嘗試使用不存在的標籤名稱存取資料時發生的錯誤。
    - **SyntaxError (語法錯誤)**：由於程式碼格式書寫不合規範導致直譯器無法解析的錯誤。
    - **ValueError (數值錯誤)**：當傳遞給函式的數值型別正確但內容不合法時發生的錯誤。
- **中繼資料 (Metadata)**：關於內容或組件自身的附加描述資訊。這就像數位相片檔案內部保存的拍攝資訊（相機型號、曝光參數、拍攝時間等）。

## 其他補充術語 {: #additional-terms }

- **Python**：構建 Griptape 的核心程式語言。相較於其他程式語言，Python 以其簡潔優雅、易讀易懂的語法結構著稱。
- **API (應用程式開發介面 / Application Programming Interface)**：允許不同軟體應用程式之間安全交換資料的一套標準協議規則。對於創作者而言，這類似於讓不同音訊硬體設備能夠無縫互連的標準連接埠與插頭規範。
- **JSON (JavaScript Object Notation)**：一種廣泛通用於儲存和傳輸結構化資料的輕量級文字格式。這如同用於整理歸檔資訊的標準化資料模板。
- **CSV (逗號分隔值 / Comma-Separated Values)**：用於儲存表格資料（如試算表）的簡單檔案格式。每行代表一筆記錄，逗號則用於區分各欄位的數值。
- **UI (使用者介面 / User Interface)**：允許使用者與軟體系統進行直觀互動的視覺元素與控制項集合，包括按鈕、滑桿、文字輸入方塊等。在 Griptape Nodes 中，我們將 UI 稱為「編輯器 (Editor)」。
- **框架 (Framework)**：提供標準基礎結構與通用功能的預先構建程式碼庫，旨在幫助開發者更輕鬆地打造自訂應用程式。框架好比藝術材料工具組，為您準備好了基礎畫架、畫布與常用底色顏料。
