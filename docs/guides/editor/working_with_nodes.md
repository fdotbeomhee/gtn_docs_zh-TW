# 節點操作指南 (Working with Nodes) {: #working-with-nodes }

本頁詳細介紹在畫布上構建工作流程的各項日常操作：添加節點、選取與移動節點、重新命名、複製、鎖定、刪除、建立參數連線以及編輯節點參數。工作流程構建完成後的執行操作請參閱[執行工作流程](running_workflows.md)；節點群組化與整理請參閱[節點分組](node_groups.md)。

## 添加節點 {: #adding-nodes }

開啟 **Add Node (添加節點)** 快顯功能表有三種方式：

- 游標懸停在畫布上方時按下 `Tab`。
- 游標懸停在畫布上方時按下 `Shift+A`。（若游標在畫布之外，按下 `Shift+A` 則會變為全選節點 — 參閱[選取與移動](#selecting-and-moving)）。
- 在空白畫布上按一下滑鼠右鍵，選擇 **Add Node**。

功能表會在游標所在位置開啟，選定節點類型後便直接放置於該處。功能表支援即時搜尋與分類樹狀瀏覽 — 輸入關鍵字即可按名稱、說明描述或標籤進行篩選。若有設定，分類清單上方還會顯示 **Favorites (常用)** 區塊（為節點加註星號即可加入）與 **Recent (最近使用)** 區塊（列出最近添加的節點類型）。

您也可以直接從左側側邊欄的 **Nodes** 標籤頁中，將目標節點拖曳至畫布上。

## 選取與移動 {: #selecting-and-moving }

點擊單個節點即可選取。按下 `Cmd/Ctrl+A` 可選取工作流程中的所有節點；按下 `Escape` 可清除選取狀態。在空白畫布上按住滑鼠拖曳框選，可選取方框涵蓋的所有節點。

按住 Shift（或 Cmd/Ctrl）並點擊其他節點可進行多選。選取多個節點後，拖曳其中任何一個節點皆可帶動整個選取群體同步移動；此時選取範圍上方會彈出浮動工具列，可批次執行套用至所有選取節點的操作 — 包含 Copy、Duplicate、Lock、Reset、Delete 與 Create Group，具體按鈕取決於 **Settings → Editor → Button Customization** 的配置。

使用方向鍵可將選取焦點移動至該方向最近的節點，這是無須動用滑鼠即可在相連節點鏈之間快速切換的高效方式。按下 `F` 可聚焦顯示目前選取的節點（若未選取任何物件則顯示完整全圖視角）；按下 `Shift+G` 可自動重排圖形版面，使其整齊有序。

## 重新命名 {: #renaming }

在工作流程中，每個節點的顯示名稱同時兼任其唯一識別碼 (Unique Identifier)，因此重新命名節點會自動連帶更新對其的所有內部引用。

若要重新命名單個節點，請選取該節點並按下 `R`，或點擊懸停時出現在名稱旁的鉛筆圖示，亦可在右鍵快顯功能表中選擇 **Rename**。輸入新名稱後按下 `Enter`（或點擊空白處）確認提交，或按 `Escape` 取消。

若要同時重新命名多個節點，請選取多個節點後按下 `R`，或右鍵點擊其中一個並選擇 **Rename**。這將彈出 **Rename nodes** 對話方塊，您只需輸入單一基礎名稱 (Base name) 便可整批套用：第一個節點使用純基礎名稱，後續節點則自動依序命名為 `Base_1`、`Base_2` 等等。

## 建立副本、複製與貼上 {: #duplicating-copying-and-pasting }

- **建立副本 (Duplicate)** (`Cmd/Ctrl+D`，或點擊節點/多選工具列上的 Duplicate 動作)：在原始節點正旁邊建立完全獨立的節點副本，不帶有任何現有連線。
- **複製 (Copy)** (`Cmd/Ctrl+C`)：將選取的節點（包含其各項參數設定值）序列化儲存至系統剪貼簿。
- **貼上 (Paste)** (`Cmd/Ctrl+V`)：從剪貼簿內容在游標位置附近生成新節點。

複製/貼上同時也是在兩個已開啟的工作流程分頁之間跨流程移動節點的標準方式：在第一個分頁中複製，切換分頁，然後在第二個分頁中貼上。

## 鎖定節點 {: #locking }

鎖定節點可保護其免於意外改動：在解除鎖定之前，已鎖定的節點無法被執行、刪除、編輯參數或添加自訂參數。

按下 `L` 鍵（支援多選批次操作）、點擊節點標頭的鎖頭圖示，或在右鍵快顯功能表中選擇 **Lock**/**Unlock** 即可切換鎖定狀態。注意：Note 便簽節點無法被鎖定 — 鎖定選項對其不適用。

## 刪除節點 {: #deleting }

選取一個或多個節點並按下 `Delete`（部分鍵盤為 `Backspace`），或使用右鍵功能表/工具列中的 **Delete Node**。刪除節點會同步移除其關聯的所有連線；但若刪除的是位於連線中間的[中繼點節點 (Dot Node)](#dot-and-reroute-nodes)，系統會自動直接重新連通兩端，確保其餘連線不被破壞。

刪除群組框僅會移除外層的群組容器 — 內部的子節點仍會保留在畫布上，僅恢復為未分組狀態。詳情請參閱[節點分組 (Node Groups)](node_groups.md#ungrouping)。

### 工作流程執行期間刪除節點 {: #deleting-while-a-workflow-is-running }

您可以在工作流程執行期間直接刪除節點，無需等待執行結束。具體後續行為取決於執行程序是否仍然需要該節點：

- **執行程序已不再需要該節點** — 原因可能是該節點已經執行完畢，或者執行鏈根本不會傳遞至該節點 — 此時工作流程會順暢繼續推進。畫布邊緣那些未連入執行鏈的獨立節點即屬於此類。
- **執行程序仍然需要該節點** — 此時執行將被立即中止取消。引擎會精確回報是哪一個下游節點仍在等待被刪除的節點輸出，讓您明確了解中止原因。當執行程序安全停止後，執行控制按鈕會立即重新亮起。

即使下游某個節點尚未開始運算，它依然被視為「必需節點」：因為後續執行終將抵達該處，若抵達時發現輸入來源遺失將導致嚴重異常。透過中間節點間接傳遞資料的節點亦同。

第二種中止機制是刻意設計的防護措施。若允許流程在缺少相依節點的情況下盲目繼續執行，系統將被迫使用該參數的預設值代替真實輸入，導致工作流程表面上顯示成功，實質上卻默默產出錯誤結果。

## 參數連線 {: #connecting-parameters }

每個可作為輸入或輸出的參數列，其邊緣都會帶有一個小型連接手柄：左側為輸入端 (Input)，右側為輸出端 (Output)。從一個手柄拖曳連線至另一個手柄即可建立連線；從某個手柄拖曳並釋放到空白畫布上，會就地彈出預先連好線的 Add Node 快顯功能表，這是串聯鏈條中「下一個」節點的極佳快捷操作。

編輯器僅允許在型別相容的連接埠之間建立連線 — 在拖曳連線過程中，畫布上型別不相容的手柄會自動變暗淡出，讓您可以一目了然看清哪些端點能夠接收連線。大多數參數支援多種資料型別（例如同時接受圖像或 URL 字串的圖像輸入端），特定支援的型別均由節點內部邏輯定義。

若要移除某條連線，點擊該連線線條將其選取並按下 `Delete`；或者懸停在連線上，點擊浮現的連線操作按鈕（需在 **Settings → Editor → Node Settings** 中啟用 **Show Connection Buttons on Hover**）。

## 中繼點與轉向節點 (Dot and reroute nodes) {: #dot-and-reroute-nodes }

**中繼點節點 (Dot Node)** 是一種純透傳、無任何運算邏輯的輔助節點，您可以將其插入既有連線的中間，用來引導連線路徑繞過其他節點，或整理複雜擁擠的畫布。當游標懸停在連線上或選取連線時，按下 `I` 鍵即可在該處插入中繼點節點 — 原始連線會自動被切分為兩段並經由中繼點串接，流經的資料內容絲毫不受影響。

刪除中繼點節點會自動重新直連其前後的兩個節點，因此移除中繼點絕不會中斷資料傳輸。

## 便簽 (Notes) {: #notes }

**便簽 (Note)** 是一種可自由放置、不參與執行的獨立文字方塊，您可以將其置於畫布各處，為自己或協同合作夥伴留下上下文註記 — 例如特定區域的功能說明、待辦事項 (TODO) 或上游依賴項目的警示。游標懸停在畫布上並按下 `N` 鍵即可就地建立便簽。

便簽無法被鎖定，且絕不參與工作流程執行，亦不受多選工具列的 Run/Reset 動作影響。

## 屬性面板 (The Properties panel) {: #the-properties-panel }

選取畫布上的節點會在右側側邊欄的 **Properties (屬性)** 面板中開啟其參數配置，內容與節點本身內嵌顯示的參數列完全一致 — 數值完全同步，只是屬性面板提供了一個專屬且常駐的檢視區塊，當節點參數眾多或節點已被折疊時，在屬性面板中操作更為舒適自如。按下 `Cmd/Ctrl+B`、在右鍵功能表中選擇 **Property Panel**，或點擊節點標頭按鈕（若有配置），皆可快速開啟右側側邊欄。

在屬性面板中編輯數值與直接在節點內嵌欄位中修改，更新的是底層完全相同的同一變數。

### 添加自訂參數 {: #adding-a-custom-parameter }

部分節點支援在原有內建參數的基礎上，讓您手動新增自訂參數。若該節點支援此功能，您會在參數清單底部（節點本體與 Properties 面板中）看到 **Add parameter** 列，或在右鍵功能表中找到 **Add parameter** 選項。

點擊後將彈出 **Add New Parameter** 對話方塊，可配置以下欄位：

| 欄位名稱 | 控制屬性說明 |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| **Name** | 參數內部變數名稱。在該節點內必須維持唯一性。 |
| **Display Name** | UI 介面呈現的標籤文字，若希望顯示與內部名稱不同的易讀標籤時使用。 |
| **Type** | 資料型別，可選 `Any`、`str`、`bool`、`int`、`float`、`dict`、`json` 或多媒體型別 `image`、`audio`、`video`。 |
| **Tooltip** | 滑鼠懸停時顯示的說明提示文字。 |
| **Input / Output** | 參數的連線方向：可作為傳入連線 (Input)、傳出連線 (Output) 或兩者兼具。 |
| **Default Value** | 在未設定任何數值或未建立連線前所採用的起始預設值。 |

依據所選的資料型別，對話方塊會展開相應的進階選項 — 例如文字型別支援多行/Markdown 切換開關，數值型別提供帶有 min/max/step 的數值滑桿，下拉選單則可自訂一組固定選項（支援自訂圖示、副標題與搜尋輸入方塊）。

### 設定現有自訂參數 {: #configuring-an-existing-custom-parameter }

自訂參數建立後，右鍵點擊該參數（或屬性面板中對應的參數列）並選擇 **Configure parameter**，即可重新開啟帶有當前設定值的配置對話方塊進行修改。此選項僅對您自行添加的自訂參數有效 — 節點原廠自帶的標準參數無法以此方式編輯。

### 隱藏已連線參數 (Hiding connected parameters) {: #hiding-connected-parameters }

開啟 **Hide Connected Parameters (隱藏已連線參數)**（按下 `Shift+H`，或前往 **Settings → Editor → Node Settings**），即可將所有輸入端已經接上連線的參數列自動折疊隱藏。這是為繁忙擁擠的工作流程清理版面的絕佳利器：一旦某個參數的數值已經由畫布其他節點動態傳入，通常您便無需再看到其靜態可編輯輸入方塊佔用空間。再次切換此開關即可立即還原完整顯示。

!!! tip "強制保持特定參數常駐顯示"

    在 Node Settings 中緊鄰主開關的 **Ignore Hide Connected (Display Nodes)** 與 **Ignore Hide Connected (Save Nodes)** 選項，可豁免任何名稱包含 "display" 或 "save" 的參數 — 當您希望即便輸入端已連線，仍隨時密切監控輸出路徑或預覽畫面時非常實用。
