# 多媒體檢視器與編輯器 (Media Viewers and Editors) {: #media-viewers-and-editors }

每當參數承載圖像、影片、音訊片段、3D 模型或高斯潑濺 (Gaussian Splat) 時，編輯器會自動切換為專為該多媒體類型打造的互動檢視器，取代傳統的純文字輸入方塊。部分檢視器同時也是功能強大的編輯器 — 您無需離開畫布，即可直接繪製遮罩 (Mask)、裁切畫格或進行多圖層合成。本頁導覽各類檢視器：出現位置、開啟方式以及各項操作功能。

呈現哪種檢視器由參數的底層型別決定：

| 參數資料型別 | 對應檢視器 |
| -------------------------------------- | ------------------------------------------------------------- |
| `ImageArtifact` / `ImageUrlArtifact`   | [圖像檢視器與右鍵操作](#viewing-an-image-and-its-right-click-actions) |
| `VideoArtifact` / `VideoUrlArtifact`   | [影片播放與對比器](#playing-and-comparing-video)                  |
| `AudioArtifact` / `AudioUrlArtifact`   | [音訊播放器](#playing-audio)                                |
| `ThreeDArtifact` / `ThreeDUrlArtifact` | [3D 模型檢視器](#viewing-3d-models)                         |
| `SplatArtifact` / `SplatUrlArtifact`   | [高斯潑濺檢視器](#viewing-gaussian-splats)             |

圖像與影片的滑動對比器並非獨立型別 — 當節點透過單一參數同時暴露兩個多媒體數值時，編輯器會自動啟用對比檢視。（節點開發者請參閱[參數 UI 參考手冊](../../development/custom_nodes/parameter_ui_reference.md)瞭解型別與小工具的完整對應關係）。

檢視器上方浮現哪些額外工具按鈕（裁切、遮罩、相機擷取等），取決於節點作者為該參數設定的選用屬性。這些屬性內嵌於節點邏輯中，這解釋了為何相同型別的圖像參數在某些節點上顯示裁切圖示，而在其他節點上則顯示遮罩圖示。

## 檢視圖像與右鍵功能表 {: #viewing-an-image-and-its-right-click-actions }

圖像參數透過標準圖像檢視器呈現：縮圖下方載明圖片名稱、解析度尺寸與檔案大小。游標懸停時會浮現放大按鈕，點擊可在燈箱視窗 (Lightbox) 中全螢幕檢視；按下 **Escape** 或點擊視窗外部即可關閉。

在任何圖像上按一下右鍵 — 無論是在節點縮圖上還是在燈箱全螢幕視圖中 — 皆會彈出功能表：

- **Copy image (複製圖像)** — 將全解析度圖像以 PNG 格式複製到系統剪貼簿（若原始檔案為其他格式，系統會自動在後台重新轉碼）。
- **Copy image URL (複製圖像 URL)** — 複製圖片的網路位址或內部路徑文字。
- **Save image (儲存圖像)** — 將全解析度圖像下載儲存至磁碟。
- **Make thumbnail (設為工作流程縮圖)** — 將此圖像指定為目前工作流程的標頭縮圖，顯示於工作流程瀏覽首頁中。這會立即更新工作流程儲存的中繼資料。

## 雙圖滑動對比 (Comparing two images with a slider) {: #comparing-two-images-with-a-slider }

當節點透過單一對比參數輸出成對的圖像時，編輯器會將其彩現為帶有可拖曳垂直分割線的單一檢視視窗：分割線左側呈現第一張圖像，右側呈現第二張圖像。在對比區域上方移動滑鼠即可滑動分割線。

游標懸停時點擊放大按鈕可在全螢幕模式下開啟對比檢視，兩側各自標註對應的檔案名稱。按 Escape 鍵即可退出。

## 圖像裁切 (Cropping an image) {: #cropping-an-image }

部分圖像參數帶有裁切按鈕（縮圖上的裁切圖示），點擊可開啟裁切編輯器。在編輯器中，拖曳覆蓋層上的操作手柄可調整裁切範圍尺寸，或使用以下輔助工具：

- **Reset All (全部重設)** — 還原至完整原始圖像。
- **外觀比例預設集 (Aspect ratio presets)** — 正方形 (Square)、16:9、3:2、4:3、9:16、2:3、3:4。
- **Zoom (縮放)** — 10–300%，畫面上以呼吸動畫虛線框進行預覽。
- **Rotation (旋轉)** — -180° 至 180°，帶有標記向上方向的箭頭指示。
- **Crop Details (裁切詳情)** — 顯示以像素 (px) 為單位的 left/top/width/height 精確數值。

點擊 **Accept & Save (接受並儲存)** 會將裁切邊界參數（left, top, width, height, zoom, rotation）寫入節點參數值中，而不會破壞性地重新烘焙新的圖片檔案 — 節點本身在後續運算時會負責套用這些裁切設定。點擊 **Cancel** 則捨棄所有變更。

## 繪製遮罩 (Painting a mask) {: #painting-a-mask }

啟用遮罩編輯的圖像參數會顯示遮罩圖示；點擊可開啟 Paint Mask (繪製遮罩) 編輯器。您可直接在覆蓋於原始影像上方的畫布上自由塗抹：

- **Brush (筆刷)**：繪製白色（顯示/保留區域）；**Erase (橡皮擦)**：繪製黑色（隱藏/遮蔽區域）。
- **Brush Size (筆刷大小)** 與 **Blur (模糊)** 滑桿可控制筆觸寬度與邊緣柔化程度。按下鍵盤上的 `[` 與 `]` 鍵可快速微調筆刷大小。
- **Show Mask / Show Composite**：在純灰階黑白遮罩與帶有透明通道的合成預覽畫面之間即時切換。
- **Invert Mask (反相遮罩)**：反轉整個遮罩的黑白分佈。
- **Reset Mask (重設遮罩)**：將遮罩還原為原始圖像自帶的 Alpha 通道狀態。
- **Flood Fill (油漆桶填滿)**：以當前選取工具的顏色填滿整個畫布。
- 按住 **Alt** 鍵並拖曳滑鼠可平移畫布，按住 **Alt** + 滾動滾輪可縮放；畫布上方亦提供專用縮放按鈕與重設視圖按鈕。

點擊 **Apply (套用)** 後的儲存行為依參數現有結構而定：若原本為純圖像，繪製內容會修改該圖片的 Alpha 透明通道並儲存為帶透明度的全新圖像；若該參數原本就綁定有獨立的遮罩檔案，繪製內容則會直接寫入該灰階遮罩檔案，原始圖像保持完全不受影響。

## Image Bash：多圖層合成與繪畫 (Compositing images and paint layers) {: #image-bash-compositing-images-and-paint-layers }

Image Bash 是編輯器內建的多圖層合成工具。部分圖像參數帶有鉛筆圖示，點擊即可直接開啟；將狀態儲存為結構化圖層資料的參數，也可透過 **Edit** 按鈕開啟同一工具。Griptape 內建節點使用 Image Bash 來將多個來源圖片與繪畫圖層組合成完整的鏡頭畫面，而非僅僅在原地微調單一圖片。

在工具內部，每個圖層可為 **圖像圖層 (Image Layer)**（您的來源圖片之一，可透過畫布變形手柄平移、縮放與旋轉）或 **筆刷圖層 (Brush Layer)**（可供繪畫的畫布）。側邊欄列出所有圖層，附帶縮圖、顯示開關、不透明度以及拖曳重排圖層順序的手柄；您可以重新命名、刪除或建立圖層副本，亦可將圖像圖層轉換複製為新的可繪製筆刷圖層。

繪畫工具提供四種筆刷類型 — Pen (鋼筆)、Soft (柔邊筆)、Crayon (蠟筆) 與 Spray (噴槍) — 每種均具備獨立的大小、色彩與不透明度控制，其中蠟筆具備斑點大小、斑點密度、散布度與密度衰減等細部參數，噴槍具備噴灑半徑與微粒密度調整。內建 50 步筆觸復原/重做歷程記錄。您亦可在工具內自由調整畫布尺寸與背景顏色。

預設筆刷與畫布尺寸可在編輯器的 Settings 設定面板中自訂 — 搜尋 "ImageBash" 即可找到該設定卡片。在此修改預設值僅影響日後新開啟的繪圖工作階段。

## 影片播放與對比 (Playing and comparing video) {: #playing-and-comparing-video }

影片參數使用畫格精準度 (Frame-accurate) 播放器：支援單格微調步進、正向/反向播放，以及在關鍵標記畫格之間快速跳轉。快速鍵與介面控制項邏輯完全一致：`←`/`→` 鍵逐格微調，`j`/`k`/`l` 鍵分別對應倒帶、暫停與播放。若節點同時公開了畫格選取參數，時間軸上會顯示畫格標記，您可自由新增（按下 `.` 鍵標記當前畫格）、拖曳調整或清除，`n`/`m` 鍵可在前後標記點之間迅速跳轉。

底部狀態列顯示即時播放畫格率 FPS（支援手動編輯，並提供重設回影片原生速率的按鈕）、當前畫格數與總畫格數、靜音與音量滑桿。展開 **Video Details (影片詳情)** 面板可閱讀解析度、檔案大小、封裝格式、視訊編碼編譯器 (Codec)、長寬比、時長與畫格率。**Enlarge (放大)** 按鈕可在大型視窗中開啟播放器；**Fullscreen (全螢幕)** 按鈕則啟動瀏覽器原生全螢幕模式。

影片對比參數將兩支影片並排呈現，具備與雙圖對比完全一致的可拖曳分割線，兩側影片逐格精準同步播放，並附帶切換開關供您選擇聆聽哪一側的音軌。

在影片上按一下右鍵可選擇 **Copy video URL** 與 **Save video**。

## 音訊播放 (Playing audio) {: #playing-audio }

音訊參數呈現為波形圖 (Waveform)，下方附有播放控制項：播放/暫停、已播放/總時長、靜音與音量滑桿。在波形圖上的任意位置點擊並拖曳滑鼠，即可即時拖曳定位 (Scrub) 至該播放時間點。

## 網路攝影機與麥克風擷取 (Capturing from a webcam or microphone) {: #capturing-from-webcam-or-microphone }

啟用攝影機擷取功能的圖像參數，在授予瀏覽器鏡頭存取權限後，會直接在縮圖位置顯示即時視訊預覽；點擊相機按鈕可拍攝靜態照片並自動上傳，拍攝成品將取代即時預覽。重新擷取按鈕可供您隨時重拍。

啟用麥克風錄製功能的音訊參數，會在波形圖旁顯示錄製按鈕。點擊開始錄製 — 按鈕會轉變為計時器狀態 — 再次點擊停止錄製；錄製完成的音訊會自動編碼並上傳。點擊垃圾桶圖示可清除已錄製音訊以便重新錄製。

兩項功能皆需要您在瀏覽器權限提示中明確授予攝影機或麥克風存取許可；若拒絕存取，介面將展示錯誤提示而無法顯示錄製控制項。

## 檢視 3D 模型 {: #viewing-3d-models }

3D 模型參數在互動式檢視器中呈現：拖曳滑鼠可環繞旋轉視角 (Orbit)、滾動滾輪縮放、按住右鍵拖曳可平移視角 (Pan)。支援的格式包含 glTF/GLB（支援 Draco 壓縮網格）、OBJ、FBX、DAE、3DS、STL 與 PLY；USDZ 檔案目前僅支援純文字 USDA 變體 — 由 Rodin 或 Apple QuickLook 等工具匯出的二進位 USDC 檔案目前無法在預覽器中彩現，但檔案本身依然安全保存並可正常下載。未內嵌專屬材質的格式（如 STL、PLY 或純 OBJ）會被套用中性預設材質，確保其幾何形體結構能夠清晰辨識。

游標懸停在檢視器上時點擊放大圖示可在全螢幕下檢視模型，並支援全螢幕自動緩慢旋轉展示。按下 Escape 鍵或點擊關閉按鈕即可結束。

## 檢視高斯潑濺 (Gaussian splats) {: #viewing-gaussian-splats }

高斯潑濺參數（支援 `.splat` 與 `.ksplat` 檔案）採用與 3D 模型檢視器完全一致的環繞/縮放攝影機視角控制，透過高斯潑濺彩現器進行即時點雲光場運算。點擊放大圖示可開啟全螢幕檢視；按下 Escape 鍵或點擊關閉按鈕即可結束。

## 從圖片中載入工作流程 (Loading a workflow from an image) {: #loading-a-workflow-from-an-image }

Griptape Nodes 能夠將工作流程的節點拓撲圖形結構，隱形內嵌於其匯出為縮圖的 PNG 圖片檔案中。當您將此類 PNG 檔案直接拖曳並放置到畫布上時，若編輯器偵測到內嵌的工作流程中繼資料，系統會彈出選項詢問您的意圖，而非單純建立圖片節點：

- **Add Image (添加為圖片)** — 視為一般圖片處理，直接建立標準的圖片載入節點。
- **Add Nodes from Workflow (從工作流程添加節點)** — 完整還原並將生成該圖片的所有節點加入您當前的工作流程中，同步匯入所引用的相依程式庫、靜態檔案以及其依賴的所有子流程。在對話方塊中展開節點、程式庫與相依清單，可在正式導入前完整預覽將被加入的組件。

若同時將多個 PNG 檔案拖入畫布，系統會彈出批次處理對話方塊：明確指出有多少張圖片內含工作流程中繼資料，並可將您的決定（全部作為圖片添加，或全部導入工作流程節點）整批套用至所有檔案。未內嵌中繼資料的普通圖片則一律自動作為普通圖片節點匯入。
