# 編輯器概述 (The Editor) {: #the-editor }

編輯器是您用來構建、執行與檢查 Griptape Nodes 工作流程的視覺化工作區。它本質上是一個無限延伸的畫布：您可以將節點拖曳至畫布上、相互連線，並運行最終結果。視窗中的其他所有介面組件 — 頂部標頭、功能表列、兩側側邊欄 — 都是為了輔助畫布而存在：命名與執行工作流程、尋找可添加的節點，以及在節點運行後深入檢查其執行狀態。

本頁將逐一導覽各個介面區域。若您需要特定操作指引，[後續導覽與進階指南](#where-to-go-next) 區塊提供有關於節點操作、節點分組、執行工作流程、多媒體編輯器與節點程式庫管理的專屬指南連結。

## 畫布 (The canvas) {: #the-canvas }

畫布是您的工作流程所在的舞台。節點是帶有輸入與輸出連接埠的方塊；節點之間的連線是您從某個節點的輸出端拖曳至另一個節點輸入端的線條。您所構建的一切自動化邏輯最終都會在此呈現。

在畫布中移動與巡覽的幾種常用方式：

- **平移 (Pan)**：按住 `Space` (空白鍵) 並拖曳滑鼠（即使游標懸停在節點上方也能正常運作），或者按住滑鼠滾輪中鍵拖曳。
- **縮放 (Zoom)**：滾動滑鼠滾輪或使用觸控板捏合手勢；也可使用左上角的縮放滑桿（若在設定中啟用），或按住 `Z` 鍵並左右拖曳滑鼠進行流暢縮放。
- **框選 (Select)**：在空白畫布上拖曳滑鼠拉出選取方框以框選多個節點，或按住 `Shift` 點擊個別節點以在目前選取集合中加入或移除節點。

畫布角落的 **小地圖 (Minimap)**（若處於隱藏狀態，可在編輯器設定中開啟）讓您一眼俯瞰整個節點圖形全貌，並可透過點擊或拖曳小地圖迅速跳轉視角。左下角的控制項按鈕群組提供了放大、縮小、最適大小檢視 (Fit view) 按鈕，以及一個 **切換純淨模式 (Toggle Clean Mode)** 按鈕，可隱藏背景裝飾性的 Griptape 浮水印圖示 — 在為您自己的工作流程截圖時非常實用。

將游標懸停在畫布上並按下 `Tab` 鍵，可在滑鼠位置就地開啟 **Add Node (添加節點)** 快顯功能表。關於節點放置後的各項操作請參閱[節點操作指南](working_with_nodes.md)，完整的畫布操作按鍵請參閱[鍵盤快速鍵](keyboard_shortcuts.md)。

## 頂部標頭 (The header) {: #the-header }

頂部標頭橫跨視窗上方，分為三個核心控制區塊。

在**左側**，側邊欄切換按鈕緊鄰[功能表列](#the-menu-bar)，接著是目前工作流程的名稱。每當存在尚未儲存的變更時，名稱末尾會帶有 `*` 標記；工作流程至少儲存過一次後，名稱下方會顯示實體檔案名稱 (`<workflow>.py`)。尚未儲存過的全新工作流程僅顯示臨時名稱，無檔案名稱列。

在**中央**為執行控制按鈕群組：

| 按鈕名稱 | 功能說明 |
| --------------------- | -------------------------------------------------------------- |
| **Run Workflow (運行工作流程)** | 從起始端完整執行整個工作流程。 |
| **Run To Selected (運行至所選)** | 執行依賴鏈，直到單個選取的目標節點為止。 |
| **Run From Selected (從所選運行)** | 以單個選取的節點為起點，向下游依序執行。 |
| **Cancel Run (取消運行)** | 中止目前正在執行中的工作流程。 |

**Run To Selected** 與 **Run From Selected** 僅在剛好選中單個節點時才會啟用。關於何謂「可執行狀態」以及局部執行的詳細機制，請參閱[執行工作流程](running_workflows.md)。

在**右側**，設有引擎選擇器（用於切換編輯器所連線的運行中引擎實例）、錯誤歷程記錄下拉選單，以及可開啟發布對話方塊的 **Publish Workflow (發布工作流程)** 按鈕。

## 功能表列 (The menu bar) {: #the-menu-bar }

功能表列位於頂部標頭的左側區塊，緊鄰側邊欄開關按鈕。包含三大主功能表。

### File (檔案) {: #file }

建立、開啟、儲存與管理目前的工作流程檔案：

- **New** / **Open...** — 建立全新工作流程或瀏覽開啟現有工作流程。
- **Rename...** — 重新命名工作流程（官方提供的範本工作流程停用此功能；請改用 Save As 另存可編輯副本）。
- **Save** / **Save As...** / **Save As New Version** — Save As New Version 會寫入新的版本化檔案（如 `my_workflow_v002.py` 等）而非直接覆寫；該選項僅在工作流程至少儲存過一次後才會出現。
- **AutoSave** — 切換開啟或關閉自動儲存功能，並附有直達其設定頁面的捷徑。
- **Refresh Libraries** — 重新整理並載入程式庫變更，無需重啟引擎。
- **Report Issue** — 提交錯誤回報單。
- **Exit** — 結束並離開編輯器。
- **Delete `<workflow name>`** — 永久刪除目前的工作流程檔案。

### Manage (管理) {: #manage }

快速跳轉至工作流程所依賴各項資源的管理介面：

- **Model Management (模型管理)** — 瀏覽與管理具備模型需求節點可取用的 AI 模型。
- **Library Management (程式庫管理)** — 安裝、更新與設定節點程式庫。完整指引請參閱[節點程式庫 (Libraries)](../libraries.md)。
- **Engine Management (引擎管理)** — 管理編輯器可連線的引擎執行個體。
- **Project Management (專案管理)** — 檢視與切換不同專案。請參閱 [GUI 專案管理指南](../projects/gui_guide.md)。

### Settings (設定) {: #settings }

匯集所有可配置項目的 **Settings** 子功能表（All Settings、Agent Settings、Editor Settings、Theme Settings、Engine Settings、File System、Libraries、Library Settings、MCP Servers、API Keys & Secrets 以及 [Beta 功能](beta_features.md)），下方還包含三項快速動作：**Copy Path to Settings**（複製設定檔路徑至剪貼簿）、**Show Settings Folder**（在系統檔案管理員中開啟設定資料夾）與 **Reset Settings to Default**（將設定重設為預設值）。

這些設定專門配置引擎與編輯器本體。若您使用的是 Griptape Nodes Desktop，應用程式專屬的整體設定 — 包含佈景主題、軟體授權、日誌檔案與更新通道 — 則位於視窗右上角帳戶功能表內的[應用程式設定 (App Settings)](../desktop/app_settings.md)。

## 左側側邊欄 (The left sidebar) {: #the-left-sidebar }

左側側邊欄是您尋找並向工作流程添加節點與程式庫的地方。標籤頁上方設有 **Favorites (常用我的最愛)** 區塊 — 為常用節點點亮星號即可將其釘選在此處，省去每次搜尋的時間 — 緊接著是一個能夠即時篩選目前使用標籤頁內容的搜尋輸入方塊。

搜尋方塊下方有兩個標籤頁：

- **Nodes (節點)** — 依功能分類組織的所有可用節點，包含內建與已安裝的自訂程式庫節點。
- **Libraries (程式庫)** — 相同的節點清單，但改為依據其所屬的程式庫來源而非功能類別進行樹狀組織。此處為檢視瀏覽模式；若要安裝、更新或移除程式庫本身，請前往 **Manage → Library Management**（詳情參閱[節點程式庫 (Libraries)](../libraries.md)）。

直接從任一標籤頁將節點拖曳至畫布即可加入工作流程。點擊頂部標頭的側邊欄切換按鈕（或使用對應快速鍵）可將側邊欄折疊為窄幅圖示欄，或將其完全關閉。

## 右側側邊欄 (The right sidebar) {: #the-right-sidebar }

右側側邊欄容納了一組標籤面板，統稱為 **Sidebar Panels**。關閉按鈕旁的下拉選單（三點圖示）允許您自訂顯示或隱藏特定面板 — 每個項目旁邊都有眼睛圖示，便於查看目前可見的面板。在此隱藏面板不會清除任何資料；重新勾選時標籤頁便會立即復原。

四大核心面板包括：

- **Chat (對話)** — 直接在編輯器內與智慧體交談互動，並可切換模型/服務提供者以及存取您所掛載的任何 MCP 伺服器。
- **Code (程式碼)** — 工作流程對應生成的 Python 程式碼，具備語法高亮編輯器，可在此搜尋程式碼甚至直接執行。
- **Logs (日誌)** — 即時執行日誌串流，支援按嚴重層級篩選（Debug、Info、Warning、Error、Critical）並支援關鍵字搜尋。
- **Properties (屬性)** — 畫布上當前所選取單個（或多個）節點的詳細參數設定。工作流程架構完成後，這裡通常是您花費最多時間的區域，用來細緻配置每個節點的輸入值。

若側邊欄處於關閉狀態，畫布右上角附近的浮動按鈕可快速重新開啟它。
