# 個人化配置 (Personalization) {: #personalization }

您可以自訂智慧體與您溝通時的語氣態度以及其具備的個人化背景資訊。前往 **Settings → Agent Settings** 並向下滾動至 **Personalization (個人化)** 區塊即可進行設定。

| 設定欄位 | 功能與控制說明 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Address me as (稱呼我為)** | 智慧體在對話中稱呼您時所使用的姓名或暱稱。 |
| **Tone (語氣風格)** | 溝通風格與口吻（例如：Concise 精簡扼要、Formal 正式莊重、Casual 輕鬆隨和）。 |
| **My role (我的角色)** | 您的職稱或專業領域 — 賦予智慧體關於您技術背景的理解。 |
| **About me (關於我)** | 自由格式的個人興趣、工作背景或任何您希望智慧體熟知的自訂背景資訊。 |
| **Additional instructions (附加指令)** | 附加在每則回應底層的額外規則 — 用於塑造特定人設、規範輸出格式或加入領域專屬的限制條件。 |

這些欄位會共同組裝為智慧體的系統提示詞 (System Prompt)。您提供的背景上下文越豐富，智慧體產出的回覆就越具備針對性與契合度。
