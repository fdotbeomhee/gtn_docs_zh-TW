# Griptape Cloud 服務供應商 {: #griptape-cloud }

Griptape Cloud 是 Griptape Nodes 系統預設的 AI 模型服務供應商。它透過 Griptape 官方託管的雲端代理統一路由請求，讓您只需憑藉單一 Griptape API 金鑰即可存取龐大的全球主流模型目錄 — 無需為每家 AI 公司繁瑣註冊個別商業帳戶或單獨配置金鑰。

## 前置設定 {: #setup }

本項目開箱即用，無需任何額外配置。若您是使用 Griptape Cloud 帳戶登入安裝 Griptape Nodes，該服務已預設處於就緒狀態。

## 支援的模型一覽 {: #available-models }

Griptape Cloud 整合了來自全球頂級 AI 實驗室的豐富模型陣容：

- **Anthropic** — Claude Opus, Sonnet, Haiku 系列
- **Google** — Gemini Pro 與 Flash 系列
- **OpenAI** — GPT 與 o 系列推理模型
- **Meta** — 開源 Llama 系列模型
- **DeepSeek** — DeepSeek V3 與 R1 推理模型

完整的支援模型清單可直接在[對話智慧體 (Agent)](../index.md)的 **Model** 下拉選單中即時查閱。
