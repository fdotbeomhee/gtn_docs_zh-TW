# MCP 伺服器 (MCP Servers) {: #mcp-servers }

**MCP servers (MCP 伺服器)** 下拉選單允許您在對話中為智慧體掛載一個或多個 MCP 伺服器。這賦予了智慧體存取外部工具的能力 — 包含本地檔案存取、即時網路搜尋、Blender、Maya 等等 — 具體取決於您預先配置了哪些伺服器。

關於如何配置與設定各類 MCP 伺服器，請參閱 [MCP 整合指南](../mcp/index.md)。

## 在對話中途動態修改伺服器 {: #editing-a-server-mid-conversation }

您對 MCP 伺服器所做的任何修改都會在您的**下一條訊息**中自動生效 — 您完全無需重新啟動引擎或重新開啟新對話。這涵蓋了伺服器組態的方方面面：啟動命令、命令列參數、環境變數、工作目錄、URL 連線位址、標頭 (Headers) 以及其專屬的 **Rules (規則)**。

儲存修改後再次發送訊息，智慧體便會直接調用更新後的伺服器。對話歷程會被完整保留，因此您只需直接提出需求即可。

未經修改的其他伺服器會保持其既有的活躍連線，因此單獨微調某個伺服器絕不會中斷或延緩其他伺服器的正常通訊。

修改後的伺服器是否需要重新建立連線，取決於您變更的具體設定項目：

- 編輯其 **Rules (規則)** 會立即生效而無需重新連線，因為每次發送新訊息時，這些規則文字都會被重新動態組裝並傳遞給智慧體。
- 編輯 Griptape Nodes 連線至該伺服器的方式 — 例如啟動命令、參數、環境變數、工作目錄、URL、標頭或逾時設定 — 則會在下一條訊息時重新建立連線，因為這些屬於通訊通訊端開啟時固定的底層參數。這可能會使智慧體在發起首次工具呼叫前產生短暫延遲。

若某個伺服器被切換為停用或直接刪除，智慧體從下一條訊息起將立即停止調用它，Griptape Nodes 亦會自動平穩關閉與其的連線通道。
