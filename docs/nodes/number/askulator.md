# Askulator {: #askulator }

## 功能概述 {: #what-is-it }

Askulator 是一個自然語言計算機節點，能夠理解並解答以日常自然語言敘述的數學問題。它利用人工智慧模型解析問題語意、執行必要的數值計算，並同時輸出完整的推導思維流程與最終答案。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 解答以自然語言描述的應用數學題目
- 獲取計算過程的逐步推理步驟 (Step-by-step Reasoning)
- 處理複雜或表意模糊的數理問題
- 執行需要常識推理解釋或估算的計算
- 在缺乏精確數字時獲取具創造性或合理的近似估算值

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 Askulator 節點新增至工作流程中
1. 於 "instruction" 參數中輸入您的數學問題敘述
1. 節點將解析問題並提供：
    - 解題思維與步驟的詳細推理說明
    - 於 "result" 輸出埠傳回最終計算答案

### 參數說明 {: #parameters }

- **instruction**：欲解答的數學問題或指令（支援日常自然語言輸入）
- **model**：用於推理計算的 AI 模型驅動（預設為 `gpt-4.1-mini`）
- **result**：最終計算產出的答案數值
- **output**：解題過程的詳細推理與推導步驟說明

### 輸出埠說明 {: #outputs }

- **result**：最終計算所得的數值答案
- **output**：解答該問題所經歷的完整思維推理文字說明

## 範例展示 {: #example }

計算例如「如果我有 3 打雞蛋並送出其中的三分之一，我還剩下多少顆雞蛋？」：

1. 將 Askulator 節點新增至工作流程中
1. 於 "instruction" 參數中輸入上述問題文字
1. 節點將依序：
    - 解析 3 打 = 36 顆雞蛋
    - 計算 36 的三分之一為 12 顆
    - 從 36 中扣除 12 顆
    - 於 "output" 引腳輸出完整的思考步驟
    - 於 "result" 引腳輸出最終數值答案（`24`）

## 實作細節 {: #implementation-details }

Askulator 內部整合了：

- 用於精準理解問題情境的自然語言處理模型
- 用於執行高精度數學計算的 Calculator 工具
- 用於將思維推理與最終答案乾淨隔離的 JSON 結構化輸出規格
- 用於即時呈現計算進度的串流更新支援

本節點兼具智慧推理與輔助估算能力，能在缺乏精準數據時給出合乎邏輯的估算，並附帶條理分明的推理說明。
