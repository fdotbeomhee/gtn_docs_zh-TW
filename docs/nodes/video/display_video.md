# DisplayVideo {: #displayvideo }

## 功能概述 {: #what-is-it }

DisplayVideo 節點用於在工作流程畫布中直接呈現並播放視訊內容。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 DisplayVideo 節點：

- 在工作流程畫布中即時檢視視訊運算成果或資訊
- 呈現來自上游各個處理步驟的視訊輸出產物
- 作為執行期間動態更新的視訊視覺化佔位節點
- 在流程畫布中建立直觀易讀的視覺標籤與成果展示
- 在工作流程的關鍵檢查點視覺化監控視訊資料流

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayVideo 節點新增至工作流程中
1. 視需求設定初始視訊數值
1. 將上游輸入連線至 "video" 參數埠，或手動選取本機視訊
1. 可將 "video" 輸出埠接駁至後續其他需要視訊輸入的節點

### 參數說明 {: #parameters }

- **video**：欲呈現播放的視訊內容（相容 VideoArtifact 與 VideoUrlArtifact 格式）

### 輸出埠說明 {: #outputs }

- **video**：原樣穿透傳遞的原生視訊內容，可供後續節點繼續引用

## 範例展示 {: #example }

建構處理並檢視視訊成果的標準工作流程：

1. 將 DisplayVideo 節點新增至工作流程中
1. 將來自 LoadVideo 節點的輸出連線至 DisplayVideo 節點的 "video" 參數埠
1. 當工作流程執行時，視訊內容將直接於節點面板內嵌播放器中即時呈現

## 重要注意事項 {: #important-notes }

- DisplayVideo 節點純粹用於視覺化檢視，**絕不對視訊內容進行任何破壞性修改**。
- 節點會以原汁原味的格式完整透傳 (Pass-through) 視訊資料。
- 廣泛相容主流視訊格式（mp4、avi、mov 等）。
- 內建播放控制器，支援播放、暫停、音量調節與進度條拖曳快進檢視。

## 常見問題排解 {: #common-issues }

- **未顯示任何視訊**：請確認上游節點已成功連線至本節點的 "video" 輸入埠。
- **視訊無法播放**：請確認傳入的視訊檔案為標準相容格式且檔案未損毀。
