# AdjustVideoEQ {: #adjustvideoeq }

## 功能概述 {: #what-is-it }

AdjustVideoEQ 節點允許您調節影片的亮度、對比度、飽和度與 Gamma 數值。它透過 FFmpeg 工業級高畫質等化濾鏡，精確微調視訊畫面的色彩與光影質感。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 AdjustVideoEQ 節點：

- 校正視訊素材的曝光過度或不足問題
- 提升暗光環境下所拍攝素材的視覺清晰度
- 出於藝術風格或色彩標準考量微調色彩飽和度
- 統一多段不同來源視訊剪輯的色調風格
- 為特定社群平台輸出定製色調規格
- 全面優化影片整體的視覺感染力

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 AdjustVideoEQ 節點新增至工作流程中
1. 將視訊來源連線至 "video" 輸入埠
1. 調節亮度 (brightness)、對比度 (contrast)、飽和度 (saturation) 與 Gamma 參數數值
1. 執行工作流程以套用 EQ 色調等化調整

### 參數說明 {: #parameters }

- **video**：欲調整的目標視訊素材（相容 VideoArtifact 與 VideoUrlArtifact 格式）

- **brightness**（亮度調整，範圍 -1.0 到 1.0，預設值：0.0）：

    - -1.0 = 極暗畫面
    - 0.0 = 原生基準亮度（預設值）
    - 1.0 = 極亮畫面

- **contrast**（對比度調整，範圍 0.0 到 3.0，預設值：1.0）：

    - 0.0 = 無對比度（純平坦灰色）
    - 1.0 = 原生基準對比度（預設值）
    - 3.0 = 極高對比度

- **saturation**（飽和度調整，範圍 0.0 到 3.0，預設值：1.0）：

    - 0.0 = 完全去色（黑白灰階影片）
    - 1.0 = 原生基準飽和度（預設值）
    - 3.0 = 鮮豔濃烈色彩

- **gamma**（Gamma 曲線調整，範圍 0.1 到 10.0，預設值：1.0）：

    - 0.1 = 中間調極致提亮
    - 1.0 = 原生基準 Gamma（預設值）
    - 10.0 = 中間調顯著壓暗

- **processing_speed**：運算速度與輸出畫質平衡模式（預設值："balanced"）

    - **fast**：極速轉碼，畫質稍有妥協（採用 ultrafast preset，CRF 30）
    - **balanced**：速度與畫質極佳平衡（採用 medium preset，CRF 23）
    - **quality**：極致清晰頂級畫質，轉碼稍慢（採用 slow preset，CRF 18）

### 輸出埠說明 {: #outputs }

- **video**：完成等化調色處理的最終視訊產物，可供後續節點繼續引用

## 範例展示 {: #example }

為昏暗沉悶的短片提亮並增添鮮活色彩：

1. 將 AdjustVideoEQ 節點新增至工作流程中
1. 將來自 LoadVideo 節點的視訊輸出連線至 AdjustVideoEQ 的 "video" 輸入埠
1. 將 "brightness" 設為 0.3 以提亮暗部
1. 將 "contrast" 設為 1.2 以強化明暗層次
1. 將 "saturation" 設為 1.5 以提升色彩濃郁度
1. 將 "gamma" 保持為 1.0 以確保中間調過渡自然
1. 執行工作流程——影片將展現明亮鮮活的調色成果
1. 輸出檔案名稱將自動格式化為 `{original_filename}_eq_b0.30_c1.20_s1.50_g1.00.{format}`

## 重要注意事項 {: #important-notes }

- AdjustVideoEQ 節點底層使用 FFmpeg 高精度等化濾波演算法。
- 各項色彩參數具備複合相互影響特性，共同塑造最終畫質。
- **音訊軌道完美保留**：原始視訊自帶的音訊軌道將無損串流複製保存。
- 轉碼處理時長取決於視訊長度、畫格率與解析度。
- 節點支援輸出即時日誌以供偵錯排查。

## 參數調校推薦設定 {: #parameter-recommendations }

- **暗光補償場景**：亮度 0.2-0.5，對比度 1.1-1.3
- **過曝修正場景**：亮度 -0.2 到 -0.5，對比度 0.8-0.9
- **灰暗平淡畫面**：對比度 1.2-1.5，飽和度 1.1-1.3
- **鮮豔生動風格**：飽和度 1.3-1.8，Gamma 0.9-1.1
- **電影膠片質感**：對比度 1.1-1.2，飽和度 0.8-0.9，Gamma 1.1-1.2
- **復古懷舊氛圍**：飽和度 0.7-0.8，Gamma 1.2-1.4

## 常見問題排解 {: #common-issues }

- **轉碼超時 (Processing Timeout)**：超大視訊檔案可能耗時較長；節點預設設有 5 分鐘安全逾時機制。
- **畫面過亮或過暗**：微調 brightness 數值——負數降低曝光，正數提升亮度。
- **色彩過度刺眼**：將 saturation 飽和度回調至 1.0 以下。
- **無視訊輸入**：請確認 "video" 輸入埠已連接至有效的視訊來源。
- **FFmpeg 錯誤**：若轉碼中斷，請檢查 logs 參數以獲取底層編碼器的詳細錯誤報告。
