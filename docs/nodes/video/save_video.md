# SaveVideo {: #savevideo }

## 功能概述 {: #what-is-it }

SaveVideo 節點允許您將工作流程中運算產生的視訊內容匯出並儲存為本機硬碟中的實體檔案。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 SaveVideo 節點：

- 將工作流程中的視訊運算成果匯出至本機
- 將處理修潤完成的視訊內容持久化儲存至磁碟
- 產生可在工作流程外部自由分發播放的視訊實體檔案
- 封裝歸檔關鍵的視訊產物以供日後隨時查閱

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 SaveVideo 節點新增至工作流程中
1. 將視訊來源連線至 "video" 輸入埠
1. 視需求設定輸出的目標檔案名稱與儲存路徑
1. 執行工作流程以將視訊寫入磁碟檔案

### 參數說明 {: #parameters }

- **video**：欲儲存的目標視訊內容（相容 VideoArtifact、VideoUrlArtifact 及字典物件）
- **output_path**：視訊檔案儲存的目標檔案路徑與檔名（預設值："griptape_nodes.mp4"）

### 輸出埠說明 {: #outputs }

- **output_path**：視訊實際儲存成功的完整本機檔案路徑

## 範例展示 {: #example }

儲存工作流程中修潤完成的視訊：

1. 將 SaveVideo 節點新增至工作流程中
1. 將來自上游處理節點的視訊輸出連線至 SaveVideo 的 "video" 輸入埠
1. 將 "output_path" 設為期望的檔案名稱（例如 `"my_video.mp4"`）
1. 執行工作流程——視訊檔案即會自動寫入指定儲存位置

## 重要注意事項 {: #important-notes }

- SaveVideo 節點相容主流視訊格式（.mp4、.avi、.mov 等）。
- 輸出路徑可包含多層子目錄結構（例如 `"videos/output.mp4"`）。
- 若檔名未輸入副檔名，系統將預設使用 `.mp4`。
- 若指定的目標目錄尚不存在，節點會自動遞迴建立該目錄。
- 您可以直接點擊介面上的儲存按鈕，透過本機檔案瀏覽器對話框選取儲存路徑。

## 常見問題排解 {: #common-issues }

- **權限遭拒 (Permission Denied)**：請確認當前系統使用者對指定的目標儲存目錄具備寫入權限。
- **路徑不合法 (Invalid Path)**：請檢查 output_path 路徑格式是否符合作業系統檔案命名規範。
- **不支援的格式規格**：請確保使用的副檔名為支援的標準視訊副檔名。
- **無視訊輸入**：請確認已將有效的視訊來源連接至 "video" 輸入埠。
