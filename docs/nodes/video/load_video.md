# LoadVideo {: #loadvideo }

## 功能概述 {: #what-is-it }

LoadVideo 節點是一個基礎積木節點，讓您能夠將本機或遠端視訊引入至工作流程中。您可以將其視為在專案中挑選並載入一段視訊檔案以供後續各項操作使用。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 引用由其他節點生成的視訊產物
- 將特定的本機硬碟視訊或網路影片傳遞給工作流程中的其他節點
- 在專案畫布中載入展示基準素材視訊
- 從硬碟載入視訊檔案進入流程管線

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 LoadVideo 節點新增至工作流程中
1. 透過檔案瀏覽器選取本機視訊檔案，或將其連線至視訊來源節點

### 參數說明 {: #parameters }

- **video**：欲載入的目標視訊（可手動選取本機檔案、輸入路徑/URL，或連線來自其他節點的輸出）

### 輸出埠說明 {: #outputs }

- **video**：已載入完成的視訊物件，可直接供流程中的其他節點接駁引用

## 範例展示 {: #example }

從電腦載入本機視訊檔案以供流程使用：

1. 將 LoadVideo 節點新增至工作流程中
1. 點擊節點介面上的**檔案瀏覽器圖示 (File Browser Icon)**，從電腦硬碟中選取視訊檔案
1. LoadVideo 節點將確保該視訊產物在工作流程的其餘分支中皆可被可靠存取

## 重要注意事項 {: #important-notes }

- LoadVideo 節點純粹負責將視訊載入並向下傳遞，**不會對視訊本身施加任何破壞性變更**。
- 您可以直接點擊檔案瀏覽器圖示，從電腦本機硬碟中直觀挑選視訊。
- 點擊預覽畫面邊角上的展開圖示，可將縮圖放大以便檢視視訊畫面細節。
- 廣泛相容主流視訊格式（mp4、avi、mov 等）。

## 常見問題排解 {: #common-issues }

- **未顯示任何視訊**：請檢查是否已正確點選本機檔案，或確認上游連線的節點是否已成功輸出視訊。
- **格式不支援**：請確認傳入此節點的是合法標準格式的視訊檔案。
