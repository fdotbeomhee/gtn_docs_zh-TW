# SplitVideo {: #splitvideo }

## 功能概述 {: #what-is-it }

SplitVideo 節點允許您依據精確的時間碼 (Timecodes) 將完整長片分割切片為多個獨立的視訊片段。它整合了 AI 智慧語意解析引擎，能深度理解多種時間碼格式語法，並在維持原始最高畫質的前提下快速完成無失真分段剪切。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 SplitVideo 節點：

- 將超長視訊切割拆解為多個易於管理的短篇章節
- 從視訊素材中精準提取特定場景或關鍵畫面區間
- 為 Instagram Reels、TikTok、YouTube Shorts 等社群平台批量製作精華短影音
- 將錄影素材拆分為獨立部分（例如片頭介紹、核心正片、片尾總結）
- 從長篇錄影中匯總提煉精彩高光片段 (Highlight Reels)
- 針對不同目標受眾或發布渠道客製化分段剪輯素材

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 SplitVideo 節點新增至工作流程中
1. 將視訊來源連線至 "video" 輸入埠
1. 在 "timecodes" 參數中填寫時間碼切割區間
1. 執行工作流程以將視訊切割為多個片段檔案

### 參數說明 {: #parameters }

- **video**：欲切割的目標視訊（相容 VideoArtifact 與 VideoUrlArtifact 格式）

- **timecodes**：定義切割邊界的時間碼清單（必填）

    支援多種語法格式：

    **基礎時間碼區間：**

    ```
    00:00:00:00-00:01:00:00
    00:01:00:00-00:02:30:00
    ```

    **附帶章節標題的時間碼（以豎線 `|` 分隔）：**

    ```
    00:00:00:00-00:00:04:07|Segment 1: 專案簡介
    00:00:04:08-00:00:08:15|Segment 2: 核心功能演示
    ```

    **結構化 JSON 陣列格式：**

    ```json
    [
      {"start": "00:00:00:00", "end": "00:01:00:00", "title": "片頭"},
      {"start": "00:01:00:00", "end": "00:02:30:00", "title": "正片內容"}
    ]
    ```

### 輸出埠說明 {: #outputs }

- **split_videos**：切割完成的所有獨立視訊片段清單（VideoUrlArtifact 陣列）
- **logs**：處理過程的詳細日誌與事件記錄

## 範例展示 {: #example }

將一段 10 分鐘的完整長片切割為三個獨立段落：

1. 將 SplitVideo 節點新增至工作流程中
1. 將來自 LoadVideo 節點的視訊輸出連線至 SplitVideo 的 "video" 輸入埠
1. 在 "timecodes" 參數中輸入以下時間碼規則：
    ```
    00:00:00:00-00:02:30:00|Segment 1: 引言與背景
    00:02:30:00-00:07:30:00|Segment 2: 深度技術剖析
    00:07:30:00-00:10:00:00|Segment 3: 結論與問答
    ```
1. 執行工作流程——影片將被精確分割為三個獨立的視訊檔案
1. 每個片段將於 split_videos 陣列輸出埠中依序供後續節點引用

## 重要注意事項 {: #important-notes }

- SplitVideo 節點內建 AI 智慧解析器，能高度容錯並理解多種時間碼語法。
- 建議時間碼採用標準 **SMPTE 規格 (HH:MM:SS:FF)**，其中 `FF` 代表精確的畫格編號 (Frames)。
- 節點會自動智慧偵測視訊的基準畫格率 (FPS) 與丟幀 (Drop-frame) 標記。
- 每個分割切片片段皆會**完整保留原始畫質與原生音訊軌道**。
- 處理時長取決於視訊原始長度與切割出的片段數量。
- 底層使用 FFmpeg 高精度時間軸剪輯管線，確保切割點無殘影無音訊爆音。
- 提供完整詳細的即時日誌記錄。

## 時間碼格式填寫規範 {: #timecode-format-guidelines }

- **畫格率相容性**：自動精確識別 24fps、25fps、29.97fps、30fps、50fps、59.94fps 及 60fps。
- **丟幀機制 (Drop frame)**：針對 29.97fps 與 59.94fps 電視廣播規格視訊自動啟用補償計算。
- **畫格數範圍 (FF)**：24fps 請填 00-23，25fps 請填 00-24，30fps 請填 00-29，依此類推。
- **分隔符號**：起訖時間之間使用連字號 (`-`)，標題名稱使用豎線 (`|`) 連接。
- **片段標題**：標題為選填項，但強烈建議填寫以便於組織歸檔。

## 常見問題排解 {: #common-issues }

- **時間碼不合法 (Invalid Timecodes)**：請確保時間碼嚴格符合 SMPTE 格式 (HH:MM:SS:FF)。
- **時間區間重疊衝突**：請檢查各片段的起訖時間是否產生不合理的交叉重疊。
- **轉碼超時 (Processing Timeout)**：超大檔案或極多片段可能耗時較長；節點預設設有 5 分鐘安全逾時機制。
- **無視訊輸入**：請確認已將有效的視訊來源連接至 "video" 輸入埠。
- **空片段報錯**：請確保每個片段的起始時間早於結束時間。
- **FFmpeg 錯誤**：若分割異常，請檢視 logs 參數以獲取底層編碼器的詳細錯誤報告。
