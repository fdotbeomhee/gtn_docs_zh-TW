# EndFlowNode {: #endflownode }

## 功能概述 {: #what-is-it }

EndFlowNode 是一個基礎結構模組，專門用於標記工作流程的終止端點。將它想像為一塊明確宣告「工作流程至此結束」的停止標誌 (Stop Sign)。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 欲明確界定並標示工作流程的結束位置
- 欲在視覺畫布上為執行路徑建立清晰明確的終端節點
- 欲確保多分支工作流程各分支皆具備合規的終止錨點

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 EndFlowNode 新增至工作流程中
1. 將其連線至流程執行鏈的最後一個節點

### 參數說明 {: #parameters }

- **control**：工作流程的控制流輸入連線埠（由前一個節點連線至此）

### 輸出埠說明 {: #outputs }

- **無 (None)** — 此節點不產出任何下游資料，純粹作為工作流程終點標記

## 範例展示 {: #example }

為一個文字生成與自動儲存的工作流程劃定終點：

1. 建立包含多個功能節點的工作流程（例如 Agent 生成文章並連線至 SaveText 儲存檔案）
1. 在執行鏈最末端新增一個 EndFlowNode
1. 將 SaveText 節點連線至 EndFlowNode 即可完成規範化閉環

## 重要注意事項 {: #important-notes }

- EndFlowNode 本身不執行額外運算 — 其主要作用在於大幅提升工作流程架構的視覺可讀性與維護性。
- 在具備多個條件分支的複雜大型流程中，可配置多個 EndFlowNode 分別標記各分支的終止。
- 善用 EndFlowNode 能使流程邏輯一目了然，便於團隊協作與交接。

## 常見問題排解 {: #common-issues }

- **流程穿透終點**：請確認未在 EndFlowNode 下游錯誤連線其他活性節點。
- **流程未推進至終點**：檢查中間各節點的控制引腳連線，確保執行訊號能順利傳遞至結尾。
