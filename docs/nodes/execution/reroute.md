# Reroute {: #reroute }

## 功能概述 {: #what-is-it }

Reroute 節點是一個排版與路由工具節點，在工作流程畫布中扮演中繼轉折錨點的角色。它能根據所建立的連線動態調整自身引腳所允許的資料型別，讓複雜龐大的工作流程接線變得井然有序。

簡而言之，它能協助您自由規律地引導、轉折並塑形節點之間的連線路徑。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 Reroute 節點：

- 工作流程過於複雜、存在大量交叉重疊連線時進行線路整理
- 欲大幅提升工作流程畫布的視覺清晰度與整潔度
- 訊號需要在畫布兩端相距遙遠的節點之間長途跨越傳遞
- 欲將多條走向平行的連線整齊匯流引導
- 欲打造更乾淨、結構更容易維護的畫布佈局

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 Reroute 節點新增至工作流程畫布中
1. 將來源節點的輸出埠連線至 Reroute 節點的輸入端
1. 將 Reroute 節點的輸出端連線至目標節點的輸入埠
1. 該節點將自動適應並無損直通傳遞相應型別的資料

### 參數說明 {: #parameters }

- **passThru**：動態轉發參數，同時兼具輸入與輸出功能，會依據接入的線路資料型別動態自適應

### 輸出埠說明 {: #outputs }

- **passThru**：無損直通輸出資料，資料內容完全不被修改

## 範例展示 {: #example }

在相距遙遠的兩個節點之間插入 Reroute 節點以優化走線：例如，將位於畫布最頂部節點的影像輸出埠連線至 Reroute 節點，再由該 Reroute 節點拉出連線至畫布最下方的影像濾鏡節點，避免斜向穿過中間密集無關的節點群。

## 重要注意事項 {: #important-notes }

- Reroute 節點不會對流經其中的任何數據產生變更或損耗。
- 它具備智慧型別感知能力，連線建立後引腳型別會自動相容匹配。
- 可串聯多個 Reroute 節點，實現直角轉折或繞行特定節點模組的複雜走線佈局。
