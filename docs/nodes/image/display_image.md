# DisplayImage {: #displayimage }

## 功能概述 {: #what-is-it }

DisplayImage 節點用於在工作流程畫布中視覺化展示影像，並同時萃取解析其像素尺寸（寬度與高度）。它既是一個直觀的畫布影像檢視器，也是一個能將影像原樣向下傳遞並輸出規格中繼資料的中繼節點。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 在工作流程中直觀檢視影像以獲得即時視覺反饋
- 獲取影像的精確解析度規格（像素寬度 width 與高度 height）
- 在檢視影像的同時將其原樣直通轉發至下游節點
- 作為管線除錯節點，檢驗特定處理階段的影像狀態

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayImage 節點新增至工作流程中
1. 將上游影像來源連線至 "image" 輸入埠
1. 影像將直接呈現在節點面板中，且其尺寸數值將於輸出端就緒（注意：尺寸引腳預設處於隱藏狀態，您可隨時在右側的屬性面板中將其勾選顯示）

### 參數說明 {: #parameters }

- **image**：欲展示的目標影像物件

### 輸出埠說明 {: #outputs }

- **image**：原汁原味直通輸出的相同影像產物，可供其他下游節點連線使用
- **width**：影像的水平像素寬度（整數）
- **height**：影像的垂直像素高度（整數）

## 範例展示 {: #example }

典型的視覺化驗證與尺寸提取工作流程：

1. 將影像來源（如 GenerateImage 或 LoadImage）連線至 DisplayImage 節點
1. 在 DisplayImage 預覽視窗中確認畫面符合預期
1. 若下游需要依據解析度動態計算（如裁切或縮放比例），可啟用並連線 width 與 height 輸出埠
1. 將 image 輸出引腳無縫連線至下游處理節點

## 重要注意事項 {: #important-notes }

- DisplayImage 節點完全不對影像數據進行任何破壞性修改，純粹負責展示與尺寸偵測。
- 對於 ImageUrlArtifact 型態的遠端影像輸入，節點會異步讀取影像檔頭以精確判定尺寸。
- 對於 ImageArtifact 記憶體產物，尺寸資訊將直接自產物屬性中讀取。
- 為了保持畫布簡潔，width 與 height 輸出引腳預設在節點外觀上處於隱藏狀態，可於節點屬性面板 (Properties Panel) 中按需啟用。

## 常見問題排解 {: #common-issues }

- **影像未顯示**：請檢查上游影像節點是否已成功執行並產生合法的影像產物。
- **尺寸顯示為 0**：這通常代表影像連線異常或檔案標頭損壞無法正確解碼解析度。
- **URL 載入延遲**：從外部遠端 URL 載入超大解析度圖片時可能需要短暫的網路傳輸時間。
