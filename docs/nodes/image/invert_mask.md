# InvertMask {: #invertmask }

## 功能概述 {: #what-is-it }

InvertMask 節點為傳入的遮罩建立完全反轉的黑白對調版本。它翻轉遮罩中的透明度與權重數值：原本不透明（白色）的區域變為完全透明（黑色），原本透明（黑色）的區域則轉變為完全不透明（白色）。此節點在建立互補遮罩或在「選取目標」與「選取背景」之間一鍵切換時極其實用。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 快速建立既有遮罩的正負相反互補版本
- 在正向選取（選取主體）與反向選取（選取背景環境）之間靈活切換
- 顛倒工作流程中的透明度過濾效果
- 為進階多圖層合成工作流程生成成對的互補遮罩
- 快速反轉下游節點所受到的遮罩約束範圍

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 InvertMask 節點新增至工作流程中
1. 將遮罩來源連線至 "input_mask" 輸入埠
1. 反轉後的遮罩產物將於 "output_mask" 輸出埠傳回

### 參數說明 {: #parameters }

- **input_mask**：欲被反轉的來源遮罩（可由 DisplayMask、PaintMask 或其他遮罩節點連線輸入）

### 輸出埠說明 {: #outputs }

- **output_mask**：黑白數值完全對調後的反轉遮罩影像產物

## 範例展示 {: #example }

將主體去背遮罩反轉為背景保護遮罩：

1. 使用 PaintMask 手動繪製或使用分割節點生成人物主體的白色遮罩
1. 將該遮罩連線至 InvertMask 節點的 "input_mask" 參數埠
1. InvertMask 節點將瞬間顛倒黑白像素，將人物區域變為黑色、周圍背景變為純白
1. 將 "output_mask" 引腳連線至 ApplyMask 節點即可實現僅對背景進行模糊或調色，而完整保護前景人物

## 重要注意事項 {: #important-notes }

- **反轉判定邏輯 (Inversion Logic)**：輸入遮罩中的純白區域（255）在輸出端變為純黑（0），純黑區域（0）變為純白（255）。
- **Alpha 通道針對性反轉**：對於 RGBA 格式遮罩，節點會專門精確反轉其 Alpha 通道，同時保護 RGB 色彩不產生雜色。
- **自動灰階預處理**：傳入非灰階格式的彩色影像時，節點會先自動將其投影為標準單通道灰階陣列後再行反轉。
- **即時動態更新**：連線一經建立或上游遮罩發生異動，反轉遮罩即刻重新運算。
- **無損 PNG 保存**：輸出檔案統一採用無損 PNG 格式。

## 常見問題排解 {: #common-issues }

- **未產生任何輸出**：請檢查 "input_mask" 輸入埠是否已正確連線。
- **效果與預期相反**：請隨時牢記遮罩反轉的核心規律：白變黑、黑變白，不透明與透明徹底對調。

## 技術實作細節 {: #technical-details }

節點智慧適配多種影像模式：

- **RGBA 影像**：僅對 Alpha 通道執行 `255 - alpha` 反轉運算，保留原始色彩通道。
- **單通道灰階 (L)**：直接對全體像素矩陣執行 `255 - value` 的補數運算。
- **其他色彩模式**：先轉換為單通道灰階圖 (L) 後再行計算。
