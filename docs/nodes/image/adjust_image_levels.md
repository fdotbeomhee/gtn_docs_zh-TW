# AdjustImageLevels {: #adjustimagelevels }

## 功能概述 {: #what-is-it }

AdjustImageLevels 節點提供了類似於 Photoshop「色階 (Levels)」工具的專業級影像調整能力。它允許您精確控制輸入色階（暗部陰影、中間調、亮部高光）與輸出階調範圍，賦予您對影像色調動態範圍與反差對比的極致掌控。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 精細調校影像的整體色調階調範圍 (Tonal Range)
- 獨立分別調節陰影暗部與高光亮部
- 透過 Gamma 伽瑪校正精確控制中間調 (Midtones) 的明暗
- 營造高動態強對比或低反差柔和的視覺效果
- 修復照片中的欠曝或過曝問題
- 匹配並統一多張影像之間的色階特徵
- 依據輸出規格要求校準階調邊界

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 AdjustImageLevels 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 調整輸入與輸出色階滑桿
1. 處理完成的影像將於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

#### 輸入色階 (Input Levels) {: #input-levels }

- **shadows**（輸入暗部，範圍 0-255，預設值：0）：輸入陰影色階黑點閥值

    - 低於此數值的像素將直接被映射為輸出陰影值
    - 數值越高，將剪裁裁切更多暗部細節（壓暗暗部）

- **midtones**（中間調，範圍 0.1-10.0，預設值：1.0）：中間調伽瑪校正係數

    - 數值 < 1.0 提亮中間調
    - 數值 > 1.0 壓暗中間調
    - 1.0 代表不變更

- **highlights**（輸入亮部，範圍 0-255，預設值：255）：輸入高光色階白點閥值

    - 高於此數值的像素將直接被映射為輸出高光值
    - 數值越低，將剪裁裁切更多亮部細節（提亮亮部）

#### 輸出色階 (Output Levels) {: #output-levels }

- **output_shadows**（輸出暗部，範圍 0-255，預設值：0）：輸出陰影目標基準值

    - 輸入端的暗部黑點將被線性映射至此數值
    - 數值越高，會將最暗的黑點拉起提亮，使畫面整體暗部發灰發亮

- **output_highlights**（輸出亮部，範圍 0-255，預設值：255）：輸出高光目標基準值

    - 輸入端的高光白點將被線性映射至此數值
    - 數值越低，會壓低最亮白點的上限，使畫面整體高光變暗柔和

### 輸出埠說明 {: #outputs }

- **output**：套用專業色階調整後的完成影像

## 範例展示 {: #example }

典型的色階調校工作流程：

1. 使用 LoadImage 節點載入影像
1. 將該影像連線至 AdjustImageLevels 節點的 "input_image" 參數埠
1. 調整色階滑桿以優化畫面質感：
    - 將 shadows 設為 20 以收斂雜散暗部噪點
    - 將 midtones 設為 0.8 提亮中間調層次
    - 將 highlights 設為 240 增強高光反差
    - 將 output_shadows 設為 10 略微柔化純黑細節
    - 將 output_highlights 設為 245 防止純白過曝
1. 將 "output" 引腳連線至 DisplayImage 檢視調整後的成果

## 重要注意事項 {: #important-notes }

- **即時響應 (Live Preview)**：移動滑桿時畫面會即時呈現調色變化。
- **RGBA 透明度完整保留**：若輸入為帶有透明通道的 RGBA 影像，將完整保留其透明度數值。
- **專業級運算精度**：底層採用查表法 (Lookup Table, LUT) 進行像素色階映射。
- **參數合法性防護**：節點內部會嚴格驗證確保 `shadows < highlights`，避免發生色調倒轉錯誤。

## 常見問題排解 {: #common-issues }

- **畫面毫無變化**：請確保滑桿已調整離開預設色階值（0, 1.0, 255）。
- **畫面階調斷層**：過度激進的數值設定可能導致色彩色階分離或細節遺失。
- **高光/暗部細節被裁切 (Clipping)**：shadows 設得過高或 highlights 設得過低會導致資訊被硬性截斷。

## 技術實作細節 {: #technical-details }

節點執行嚴謹的三階段色彩轉換：

1. **輸入色階映射 (Input Levels)**：依據設定的黑點與白點閥值，對輸入像素進行範圍裁切與正規化線性縮放。
1. **伽瑪非線性轉換 (Gamma Correction)**：利用乘冪轉換函式對中間調進行非線性曲率校正。
1. **輸出色階映射 (Output Levels)**：將校正後的數值線性映射至目標輸出色階區間。
