# Image Grid Splitter {: #image-grid-splitter }

## 功能概述 {: #what-is-it }

Image Grid Splitter 節點接收一張包含**規則網格 (Regular Grid)**的多圖拼貼影像，並自動將其精確切割拆解為一張張獨立的單圖產物。

它具備以下強大特色：

- **智慧自動 (Auto)** 網格偵測演算法（盡力最佳化推算行列）
- **手動指定 (Manual)** 網格行列維度（自訂 Rows 列數與 Columns 欄數）
- 帶有黃色虛線網格輔助線的**即時預覽圖層 (Preview Overlay)**
- 同時支援**清單聚合輸出 (List)** 與**各儲存格具名輸出埠**（如 `r1c1`、`r1c2` 等）

## 適用情境 {: #when-would-i-use-it }

當您擁有一張包含多幅圖像的九宮格或拼貼圖片（例如 Midjourney 產出的 2×2 四宮格或 3×3 網格），且您希望進行以下操作時使用：

- 將每個網格磚塊獨立解構提取為單獨影像，以便進行下游批次處理
- 將特定的個別網格儲存格精準連線分流給不同的下游節點
- 同時獲得彙整好的清單產物與易於連線的各單元具名輸出埠

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 **Image Grid Splitter** 節點新增至工作流程中
1. 將多圖拼貼影像連線至 **Input Image** 輸入埠
1. 選擇 **Grid Detection** 偵測模式：
    - **auto**：由節點自主推估行列數量
    - **manual**：手動指定具體的 **Rows**（列數）與 **Columns**（欄數）
1. 檢視 **Preview** 輸出引腳，確認黃色虛線切割線是否精確貼合網格邊界
1. 執行節點以正式生成切分後的獨立影像

!!! info "自動偵測屬於盡力推估機制 (Best-Effort)"

    Auto 自動模式預設畫面為**均等尺寸的規則網格**。當相鄰圖片的邊界不明顯或視覺特徵高度相近時，演算法推估可能會產生偏差。
    若預覽虛線未準確吻合您的網格，請直接切換至 **manual** 手動模式。

### 參數說明 {: #parameters }

- **Input Image**：欲被切割拆解的網格影像。接收 `ImageArtifact` 或 `ImageUrlArtifact`。
- **Grid Detection**：
    - **auto**：自動分析影像頻譜並偵測規則網格
    - **manual**：使用手動明確指定的行列數值
- **Rows / Columns**（僅於手動模式下顯示）：滑桿控制器，範圍 1 至 12。
- **Preview**（預覽引腳）：繪製有黃色虛線分割邊界的原始影像疊加圖。
- **Detections (auto)**（自動偵測資訊組）：顯示自動偵測到的行列數量與總卡片數（手動模式下自動隱藏）。

### 輸出埠說明 {: #outputs }

- **Images**：包含所有切分後影像的 `ImageUrlArtifact` 清單，嚴格按以列為主 (Row-major) 的順序排列（由左至右、由上至下）。
- **Grid Cells**：為每個儲存格單元獨立生成的單圖輸出埠，標準命名規範為：
    - `r1c1`、`r1c2`、...、`r{row}c{col}`（例如 r1c1 代表第 1 列第 1 行）

!!! note "各單元專屬輸出引腳於執行時動態建立"

    具名的 `r{row}c{col}` 輸出引腳會在您執行節點時，依據選定或偵測出的網格維度自動在節點外觀上動態生成並綁定。

## 範例展示 {: #example }

若傳入一張 2×2 的四宮格拼貼影像：

- `r1c1` 對應左上角單圖
- `r1c2` 對應右上角單圖
- `r2c1` 對應左下角單圖
- `r2c2` 對應右下角單圖

而聚合輸出埠 `Images` 將按順序包含 `[r1c1, r1c2, r2c1, r2c2]` 清單。

## 常見問題排解 {: #common-issues }

- **預覽網格線未對齊**：直接切換至 **manual** 模式，並手動拖曳設定正確的 Rows 與 Columns。
- **自動偵測結果異常**：部分拼貼圖邊界缺乏鮮明分隔縫隙；此時 manual 模式是最可靠精確的保證方案。
