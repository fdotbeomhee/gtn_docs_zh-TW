# LoadImage {: #loadimage }

## 功能概述 {: #what-is-it }

LoadImage 節點是一個基礎積木節點，讓您能夠將本機或遠端影像引入至工作流程中。您可以將其視為在專案中挑選並載入一張實體照片以供後續各項操作使用。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 引用由其他節點（例如 GenerateImage）生成的影像產物
- 將特定的本機硬碟檔案或網路圖片傳遞給工作流程中的其他節點
- 在專案畫布中載入展示基準素材影像

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 LoadImage 節點新增至工作流程中
1. 透過檔案瀏覽器選取本機圖片，或將其連線至影像產物來源（例如 GenerateImage 節點）

### 參數說明 {: #parameters }

- **image**：欲載入的目標影像（可手動選取檔案、輸入路徑/URL，或連線來自其他節點的輸出）

### 輸出埠說明 {: #outputs }

- **image**：已載入完成的影像物件，可直接供流程中的其他節點接駁引用

## 範例展示 {: #example }

將生成的影像載入並轉發至後續處理流程：

1. 將 GenerateImage 節點的 "output" 輸出埠連線至 LoadImage 節點的 "image" 輸入埠
1. LoadImage 節點將確保該影像產物在工作流程的其餘分支中皆可被可靠存取

## 重要注意事項 {: #important-notes }

- LoadImage 節點純粹負責將影像載入並向下傳遞，不會對影像本身施加任何破壞性變更。
- 您可以直接點擊節點介面上的**檔案瀏覽器圖示 (File Browser Icon)**，直接從電腦本機硬碟中直觀挑選圖片。
- 點擊預覽畫面邊角上的展開圖示，可將縮圖放大以便檢視細節。

## 常見問題排解 {: #common-issues }

- **未顯示任何圖片**：請檢查是否已正確點選本機檔案，或確認上游連線的節點是否已成功輸出影像。
- **影像型別不相容**：請確認傳入此節點的是合法規格的 ImageUrlArtifact、ImageArtifact 或正確的本機檔案絕對路徑與 URL 字串。
