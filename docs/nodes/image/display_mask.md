# DisplayMask {: #displaymask }

## 功能概述 {: #what-is-it }

DisplayMask 節點藉由從輸入影像中提取特定通道（紅、綠、藍或 Alpha 透明度），生成對應的遮罩 (Mask) 影像。產生的遮罩為單通道灰階影像，其中白色區域代表完全不透明（或該通道數值飽和），黑色區域則代表完全透明（或該通道數值歸零）。此節點對於視覺化檢視與處理影像中的透明度通道或個別色彩通道極具價值。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 將影像中的透明度資訊提取為肉眼可見的單通道灰階遮罩
- 將特定色彩通道（紅、綠、藍）獨立提取為遮罩
- 為影像編輯管線（如去背、局部重繪 Inpainting）製作基礎遮罩
- 視覺化分析影像各通道的資訊分佈
- 產生供其他影像處理節點（如 ApplyMask）使用的標準遮罩
- 診斷並除錯影像處理流水線中的 Alpha 透明通道異常

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayMask 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 自 "channel" 下拉選單中選取欲提取的目標通道
1. 生成的灰階遮罩影像將於 "output_mask" 輸出埠傳回

### 參數說明 {: #parameters }

- **input_image**：欲自其中提取遮罩的來源影像（可由其他影像節點連線傳入）
- **channel**：欲提取作為遮罩的通道（alpha 透明度、red 紅、green 綠或 blue 藍）

### 輸出埠說明 {: #outputs }

- **output_mask**：由所選通道資料生成的灰階遮罩影像產物

## 範例展示 {: #example }

提取 RGBA 影像的透明去背區域作為黑白遮罩：

1. 使用 LoadImage 載入帶有透明背景的 PNG 照片
1. 將該影像連線至 DisplayMask 節點的 "input_image" 參數埠
1. 將 channel 選定為 "alpha"（預設選項）
1. DisplayMask 節點將即時解離 Alpha 通道，生成白（不透明主體）黑（透明背景）分明的灰階遮罩
1. 將 "output_mask" 引腳連線至 DisplayImage 節點檢視或傳入下游修圖節點

## 通道選項詳解 {: #channel-options }

- **alpha**：提取透明度通道（預設值）- 清楚檢視畫面的透明去背分佈
- **red**：提取紅色通道 - 用於隔離畫面中的紅色調元素
- **green**：提取綠色通道 - 用於隔離畫面中的綠色調元素
- **blue**：提取藍色通道 - 用於隔離畫面中的藍色調元素

## 重要注意事項 {: #important-notes }

- **標準灰階規格**：輸出的遮罩一律為高對比度灰階圖，白色代表高強度數值，黑色代表低強度數值。
- **即時響應運算**：當來源影像更新或切換通道時，遮罩會即時動態重新計算並渲染。
- **無損 PNG 儲存**：生成的遮罩產物自動以標準無損 PNG 格式寫入保存。
- **色彩模式支援**：全面支援 RGB、RGBA、純灰階 (L) 以及帶透明度的灰階 (LA) 模式。

## 常見問題排解 {: #common-issues }

- **未產生任何輸出**：請檢查 "input_image" 輸入埠是否已正確連線。
- **遮罩呈現全黑**：說明該通道在該圖中毫無訊號（例如完全透明的 Alpha 或無藍色像素）。
- **遮罩呈現全白**：說明該通道在全圖中皆處於最大值（例如不含透明背景的普通照片）。
- **缺少 Alpha 通道**：若輸入為純 RGB 影像且選取了 alpha，節點會自動安全回退為提取紅色通道。
