# AdjustImageEQ {: #adjustimageeq }

## 功能概述 {: #what-is-it }

AdjustImageEQ 節點讓您能透過精確的亮度 (Brightness)、對比度 (Contrast)、飽和度 (Saturation) 與 Gamma 伽瑪校正滑桿，微調影像的視覺外觀。它就像在您的工作流程中內建了專業的照片調色等化器，讓您對影像的色調表現擁有全盤掌控。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 增強影像亮度與對比度以提升畫面清晰度
- 調整色彩飽和度，使畫面更加鮮豔奪目或轉為沉穩柔和
- 套用 Gamma 校正以修復畫面曝光過度或不足的問題
- 在將影像傳遞給下游分析或生成節點前進行前置色彩調校
- 為多張影像建立統一且連貫的光影基調
- 依據特定輸出目標規格預調影像色調

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 AdjustImageEQ 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 調整等化器滑桿以微調影像外觀
1. 處理完成的影像將於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

#### 調色參數設定 (Adjustment Settings) {: #adjustment-settings }

- **brightness**（亮度，範圍 0.0-3.0，預設值：1.0）：控制影像整體明暗度

    - 數值 < 1.0 使影像變暗
    - 數值 > 1.0 使影像變亮
    - 1.0 代表不變更

- **contrast**（對比度，範圍 0.0-3.0，預設值：1.0）：控制畫面亮部與暗部的明暗反差

    - 數值 < 1.0 降低對比（畫面趨於灰平）
    - 數值 > 1.0 提高對比（明暗反差更加強烈）
    - 1.0 代表不變更

- **saturation**（飽和度，範圍 0.0-3.0，預設值：1.0）：控制色彩鮮豔純度

    - 數值 < 1.0 降低飽和度（趨向黑白灰階）
    - 數值 > 1.0 提高飽和度（色彩更加濃郁鮮明）
    - 1.0 代表不變更

- **gamma**（伽瑪校正，範圍 0.1-10.0，預設值：1.0）：控制畫面中間調 (Midtones) 的明暗分佈

    - 數值 < 1.0 提亮中間調細節
    - 數值 > 1.0 壓暗中間調細節
    - 1.0 代表不變更

### 輸出埠說明 {: #outputs }

- **output**：套用 EQ 等化調色設定後的完成影像

## 範例展示 {: #example }

典型的影像質感增強工作流程：

1. 使用 LoadImage 載入照片或使用 GenerateImage 生成影像
1. 將該影像連線至 AdjustImageEQ 節點的 "input_image" 參數埠
1. 調整滑桿以達到理想外觀：
    - 將 brightness 提高至 1.2 提亮畫面
    - 將 contrast 提高至 1.1 加深陰影立體感
    - 將 saturation 提高至 1.3 增強色彩鮮豔度
    - 將 gamma 微調至 0.9 凸顯中間調暗部細節
1. 將 "output" 引腳連線至 DisplayImage 節點檢視最終成果

## 重要注意事項 {: #important-notes }

- **即時預覽 (Live Preview)**：拖曳滑桿時畫面會即時動態響應套用變更。
- **RGBA 透明度完整保留**：若輸入為帶有透明通道的 RGBA 影像，將完整保留其透明度數據。
- **高畫質調校**：底層採用 PIL 的 ImageEnhance 模組，提供專業級別的高品質像素運算。
- **非破壞性編輯**：工作流程中的原始來源影像數據不會被篡改。

## 常見問題排解 {: #common-issues }

- **畫面毫無變化**：請確認滑桿數值是否已離開預設的基準值 `1.0`。
- **畫面失真過曝**：請避免設定過度極端的滑桿數值，微調細緻的參數通常能獲得最自然的視覺效果。
- **色偏現象**：大幅度調整 Gamma 可能會影響畫面的整體色彩平衡，請綜觀整體畫面進行調配。

## 技術實作細節 {: #technical-details }

節點使用 PIL 的 ImageEnhance 模組與查表法 (LUT) 實現精確調色：

- **亮度 Brightness**：將每個像素的數值乘以指定的亮度因子。
- **對比度 Contrast**：採用 PIL 的對比增強演算法調整像素動態範圍。
- **飽和度 Saturation**：透過 PIL 顏色增強演算法調控色相與純度。
- **伽瑪 Gamma**：利用色彩對應查詢表 (Lookup Tables, LUT) 精準計算非線性中間調映射。
