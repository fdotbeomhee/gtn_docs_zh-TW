# DisplayChannel {: #displaychannel }

## 功能概述 {: #what-is-it }

DisplayChannel 節點藉由從輸入影像中提取特定色彩通道（紅、綠、藍或 Alpha），生成對應的單通道遮罩影像。此節點的功能類似於 DisplayMask，但其預設提取的是**紅色通道 (Red Channel)**而非 Alpha 透明通道。生成的遮罩為灰階影像，其中白色區域代表該通道數值較高，黑色區域則代表該通道數值較低。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 將特定的色彩通道（紅、綠、藍）獨立提取為獨立影像
- 分析影像中個別色彩通道的亮度強度分佈
- 基於特定色彩通道資訊為影像編輯管線構建精確遮罩
- 視覺化檢驗不同色彩通道對整體畫面的貢獻程度
- 產生色調遮罩以供其他影像處理節點（如 ApplyMask）引用
- 診斷並除錯影像處理流水線中的色偏或通道分離問題
- 專注於紅色通道的特徵萃取（節點預設模式）

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayChannel 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 自 "channel" 下拉選單中選取欲提取的目標通道（預設為 "red"）
1. 產生的灰階通道影像將於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

- **input_image**：欲自其中提取通道的來源影像（可由其他影像節點連線傳入）
- **channel**：欲提取作為遮罩的通道（red 紅、green 綠、blue 藍或 alpha 透明度）- 預設為 "red"

### 輸出埠說明 {: #outputs }

- **output**：從輸入影像選定通道中提取生成的灰階遮罩影像產物

## 範例展示 {: #example }

提取紅色通道作為特殊遮罩：

1. 使用 LoadImage 載入照片或使用 GenerateImage 生成影像
1. 將影像連線至 DisplayChannel 節點的 "input_image" 參數埠
1. 節點預設將自動提取紅色通道，您亦可依需手動切換至其他通道
1. DisplayChannel 節點將即時解離該通道並呈現為對比分明的灰階遮罩
1. 將 "output" 引腳連線至 DisplayImage 檢視該通道的強度分佈，或連線至 ApplyMask 進行局部透明度裁切

## 通道選項詳解 {: #channel-options }

- **red**：提取紅色通道（預設值）- 非常適合用於分離畫面中的紅色元素或暖色特徵
- **green**：提取綠色通道 - 常用於植被、自然綠景等綠色元素的隔離辨識
- **blue**：提取藍色通道 - 常用於天際線、水體等冷色調特徵的隔離提取
- **alpha**：提取透明度通道 - 用於視覺化檢視影像哪些區域為透明或半透明

## 重要注意事項 {: #important-notes }

- **預設通道差異**：與 DisplayMask 節點不同，本節點預設選用 "red" 通道而非 "alpha"。
- **標準灰階輸出**：提取後的產物為純灰階圖（單通道或三通道等值灰度），白代表強、黑代表弱。
- **即時響應運算**：當來源影像更新或切換選定通道時，節點會即時重新運算渲染。
- **無損 PNG 儲存**：生成的單通道遮罩統一以無損 PNG 檔案規格保存。
- **色彩模式相容性**：全面支援 RGB、RGBA、灰階 (L) 以及帶透明度的灰階 (LA) 模式。

## 常見問題排解 {: #common-issues }

- **未產生任何輸出**：請檢查來源影像是否已正確接駁至 "input_image" 輸入埠。
- **遮罩呈現全黑**：代表選定的色彩通道在全圖中的像素強度皆接近 0。
- **遮罩呈現全白**：代表該通道在全圖中的像素數值均處於滿載飽和狀態 (255)。
- **模式不相容提示**：RGB 影像本身不具備原生 Alpha 通道，若選取 alpha 會自動安全回退為紅色通道。

## 與 DisplayMask 節點的本質區別 {: #difference-from-displaymask }

DisplayChannel 與 DisplayMask 之間的核心差異在於**預設的通道選取取向**：

- **DisplayChannel**：預設選取 **"red" (紅色通道)**
- **DisplayMask**：預設選取 **"alpha" (透明度通道)**

這使得 DisplayChannel 更契合色彩維度的分析與色度遮罩製作，而 DisplayMask 則更專注於去背與透明度檢查。
