# Webcam {: #webcam }

## 功能概述 {: #what-is-it }

Webcam 節點允許您直接從裝置的攝影機擷取即時影像。它非常適合用於即時拍照、打造互動式工作流程，或將真實世界的即時鏡頭輸入整合至您的影像處理管線中。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 從網路攝影機 (Webcam) 或外接相機擷取畫面
- 構建即時影像處理工作流程
- 開發具備鏡頭即時輸入的互動式 AI 應用
- 拍下照片進行即時分析或局部修潤
- 搭建即時影像特徵識別或偵測系統
- 製作基於攝影機觸發的自動化流水線

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 Webcam 節點新增至工作流程中
1. 點擊介面上的 "Capture"（拍照擷取）按鈕進行拍攝
1. 擷取到的影像產物將即刻於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

#### 攝影機設定 (Camera Settings) {: #camera-settings }

- **camera_index**（範圍 0-10，預設值：0）：欲選用的攝影機硬體索引編號（適用於連接多台相機裝置的情境）

- **resolution**：擷取畫面解析度規格

    - **640x480**：標準解析度 (VGA)
    - **1280x720**：高畫質解析度 (HD 720p)
    - **1920x1080**：全高畫質解析度 (Full HD 1080p)
    - **Custom**：自訂解析度的寬度與高度

- **custom_width**（像素）：當解析度選為 "Custom" 時的自訂寬度

- **custom_height**（像素）：當解析度選為 "Custom" 時的自訂高度

#### 擷取設定 (Capture Settings) {: #capture-settings }

- **auto_capture**（布林值，預設值：false）：是否啟用定時自動連續拍照
- **capture_interval**（秒，預設值：1）：自動拍照的間隔秒數

### 輸出埠說明 {: #outputs }

- **output**：從鏡頭拍攝擷取的單幀完成影像產物

## 範例展示 {: #example }

標準網路攝影機擷取與檢視流程：

1. 將 Webcam 節點新增至工作流程畫布中
1. 配置鏡頭參數：
    - 將 camera_index 保持為 0 以選取系統預設鏡頭
    - 將 resolution 解析度切換為 "1280x720" 以獲取 HD 高清畫質
1. 點擊 "Capture" 按鈕拍攝一張相片
1. 將 "output" 輸出埠連線至 DisplayImage 節點檢視拍攝成品
1. 可選擇進一步連線至其他影像處理節點（例如 AdjustImageEQ 或 DescribeImage）進行分析處理

## 重要注意事項 {: #important-notes }

- **鏡頭存取權限**：節點需要作業系統授予攝影機裝置存取權限才能正常驅動。
- **即時拍攝特性**：每次點擊 "Capture" 按鈕時，皆會從鏡頭視訊串流中擷取最新一幀畫面。
- **多相機切換**：若電腦搭載多個視訊裝置（例如筆電內建鏡頭與外接 USB 視訊鏡頭），可切換 camera_index 進行選擇。
- **解析度相容性**：自訂解析度受限於實體鏡頭硬體感光元件支援的標準規格。

## 常見問題排解 {: #common-issues }

- **找不到攝影機 (No Camera Found)**：請確認相機硬體已穩固連接，且未被其他軟體（如 Zoom、OBS 或通訊軟體）獨佔佔用。
- **權限遭拒 (Permission Denied)**：請於作業系統設定中開啟應用程式對攝影機的存取權限。
- **畫面模糊或起格**：可提高 resolution 解析度設定，或改善環境光照條件。
- **相機忙碌中 (Camera Busy)**：請關閉背景可能正在存取鏡頭的視訊通話軟體。

## 技術實作細節 {: #technical-details }

Webcam 節點運用底層作業系統的視訊擷取架構：

- 自動枚舉可用相機硬體節點與驅動
- 以指定畫面更新率與解析度抓取視訊幀
- 即時轉換為 PIL 相容影像記憶體緩衝區
- 支援非同步串流定時自動抓取 (Auto-capture)
