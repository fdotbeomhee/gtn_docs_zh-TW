# CompareImages {: #compareimages }

## 功能概述 {: #what-is-it }

CompareImages 節點允許您將兩張影像並排 (Side-by-side) 呈現對比，使您能夠直觀比對細微差異、評估調色效果或比對同一影像的不同處理版本。它是進行 A/B 測試、品質控制 (QC) 以及分析各類影像處理操作前後效果的理想工具。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 對比影像處理前後的「處理前 (Before)」與「處理後 (After)」版本
- 針對不同 AI 影像生成提示詞進行 A/B 橫向對比測試
- 評估不同影像濾鏡或等化參數設定的成色優劣
- 比對同一張素材在不同解析度或壓縮品質下的差異
- 分析特定色彩調整與銳化濾鏡的微觀影響
- 在影像處理工作流程中執行視覺品管驗收
- 同時呈現多種視覺備選方案供人工評審

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 CompareImages 節點新增至工作流程中
1. 將兩個影像來源分別連線至 "image1" 與 "image2" 輸入埠
1. 節點將在畫面上生成左右並排的視覺對比展示

### 參數說明 {: #parameters }

- **image1**：參與對比的第一張影像（呈現在左側）
- **image2**：參與對比的第二張影像（呈現在右側）

### 輸出埠說明 {: #outputs }

- **comparison**：整合了兩張影像左右並排佈局的複合對比影像產物

## 範例展示 {: #example }

典型的影像調色前後對比工作流程：

1. 使用 LoadImage 節點載入原始照片
1. 透過 AdjustImageEQ 節點對照片進行調色增強
1. 將原始照片連線至 CompareImages 節點的 "image1" 輸入埠
1. 將調色後的照片連線至 CompareImages 節點的 "image2" 輸入埠
1. 該節點將即時以左右並排視角展示前後成果，方便一目了然地審閱對比

## 重要注意事項 {: #important-notes }

- **並排視覺化佈局 (Side-by-Side Display)**：畫面採用專業的左右拼圖佈局，便於人眼快速掃視細微差異。
- **自適應縮放對齊 (Automatic Scaling)**：影像會自動依據畫布檢視大小進行等比縮放，確保兩側具備一致的對稱尺寸。
- **即時動態更新**：當任一來源影像發生變動時，對比圖將自動即時重新渲染。
- **高畫質保真度**：在縮放與拼接過程中嚴格保留高解析度像素細節，以供嚴苛的品質檢視。

## 常見問題排解 {: #common-issues }

- **畫面未顯示內容**：請確認 image1 與 image2 兩個輸入埠皆已確實接駁來源節點。
- **影像顯示過小**：節點會依據畫布容器等比自適應縮放，可拖曳放大節點視窗以獲得更大的檢視區域。
- **版面佈局配置**：左右並排佈局為系統預設的最佳對比視圖。

## 技術實作細節 {: #technical-details }

節點內部自動量測兩張影像的尺寸特徵，並建立整合畫布：

- 精準對齊兩張影像的高度維度
- 生成帶有視覺分隔的並排複合影像 (Composite Image)
- 輸出標準 ImageUrlArtifact 產物，方便在下游展示或直接匯出保存
