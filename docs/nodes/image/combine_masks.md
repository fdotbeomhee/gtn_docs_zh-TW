# CombineMasks {: #combinemasks }

## 功能概述 {: #what-is-it }

CombineMasks 節點透過取**每個像素點的最大值**（即邏輯聯集聯集運算 Union Operation），將多張遮罩影像清單合併為單一整合遮罩。

當前置的物件分割 (Segmentation) 節點輸出多個獨立區域遮罩，而您需要一個統一遮罩以便後續一次性套用時，此節點非常實用。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 將多個獨立物件的分割遮罩合併為單一遮罩
- 將多個偵測目標聚合為單一「主體去背遮罩 (Subject Mask)」
- 簡化僅接收單一遮罩輸入的下游節點工作流程

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 CombineMasks 節點新增至工作流程中
1. 將一個或多個遮罩連線至 `masks` 輸入埠（以清單形式傳入）
1. 使用 `output_mask` 輸出埠作為合併後的整合遮罩

### 參數說明 {: #parameters }

- **masks**：欲合併的遮罩影像清單物件

### 輸出埠說明 {: #outputs }

- **output_mask**：合併後的整合遮罩影像產物（PNG 格式）

## 重要注意事項 {: #important-notes }

- **聯集運算邏輯 (Union logic)**：對於畫面中的每個像素位置，輸出遮罩會取所有輸入遮罩中該位置的像素最大值（255 代表全白不透明，0 代表全黑透明）。
- **尺寸一致性要求 (Size requirement)**：傳入的所有遮罩必須具備**完全相同的像素解析度尺寸**。若尺寸不同，節點驗證將會失敗並拋出明確錯誤提示。
- **透明度通道支援 (Alpha handling)**：若輸入遮罩具備 RGBA 或 LA 格式，節點會優先提取其 **Alpha 通道** 作為遮罩權重；否則會自動將影像轉換為單通道灰階陣列進行運算。
