# PaintMask {: #paintmask }

## 功能概述 {: #what-is-it }

PaintMask 節點允許您從輸入影像建立完全可互動編輯的遮罩，並提供筆刷塗鴉繪製介面以手動修改透明度。它會自動從影像的 Alpha 通道生成初始遮罩，並呈現直觀的互動式畫布供您手動畫筆修潤。該節點還會即時將繪製後的遮罩套用回原圖，同步輸出帶有透明度的最終合成畫面。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 為影像編輯與合成管線製作自訂去背遮罩
- 人工手動精修演算法自動生成的瑕疵遮罩
- 透過筆刷在影像上任意塗抹透明或半透明效果
- 為局部重繪 (Inpainting) 或多圖層疊加製作精準的選區遮罩
- 精細微調遮罩的羽化與實體邊緣邊界

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 PaintMask 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 節點將自動依據該影像的原生 Alpha 通道生成初始黑白遮罩
1. 使用 "output_mask" 參數區域中的筆刷繪圖工具直接在畫面上進行修潤塗鴉
1. 套用手繪遮罩後的最終影像產物將於 "output_image" 輸出埠傳回

### 參數說明 {: #parameters }

- **input_image**：欲自其中生成並繪製遮罩的目標影像（可由其他影像節點連線傳入）

### 輸出埠說明 {: #outputs }

- **output_mask**：可互動繪製的黑白遮罩影像（供筆刷即時塗鴉修潤）
- **output_image**：已套用最新手繪遮罩透明度後的最終合成影像

## 範例展示 {: #example }

手動微調 AI 去背照片的主體輪廓：

1. 使用 LoadImage 載入照片或使用 GenerateImage 生成畫面
1. 將該影像連線至 PaintMask 節點的 "input_image" 參數埠
1. 節點會自動提取原圖輪廓生成初版遮罩
1. 在 "output_mask" 畫布面板中挑選白筆刷補齊主體缺失細節，或用黑筆刷擦除多餘背景噪點
1. "output_image" 將即時同步呈現最新修潤後的精緻去背成果
1. 將 "output_image" 引腳連線至 DisplayImage 節點檢視最終透明度

## 重要注意事項 {: #important-notes }

- **自動初始遮罩生成**：若傳入影像自帶 Alpha 通道，會自動轉換為基準黑白圖層以供手動微調。
- **直觀互動筆刷**：內建原生畫筆與橡皮擦工具，支援直接在瀏覽器畫布中流暢繪圖。
- **編輯狀態持久化**：只要來源影像 URL 未變更，您精心繪製的遮罩狀態會持續穩定保留。
- **紅色通道映射規範**：手繪遮罩預設使用**紅色通道 (Red Channel)**數值作為最終影像的 Alpha 透明度。
- **即時動態更新**：筆刷每次落筆繪製完成後，output_image 會即刻同步反映變更。

## 常見問題排解 {: #common-issues }

- **未產生任何輸出**：請檢查 "input_image" 輸入埠是否已正確連線。
- **繪製操作無反應**：請確認您是在 "output_mask" 的專屬畫布視窗中進行筆刷操作。
- **透明度理解注意**：**白色區域代表實體不透明，黑色區域代表完全透明去背**。

## 技術實作細節 {: #technical-details }

節點內部管線依序執行：

1. **初始遮罩萃取**：解析輸入影像並將其 Alpha 通道轉化為標準單通道灰階陣列。
1. **互動畫布同步**：將畫布上的筆刷像素異動即時同步至快取陣列中。
1. **紅色通道作為 Alpha**：提取繪製完成遮罩的紅色通道數值，並透過 `putalpha()` 注入至原圖形成 RGBA 產物。
1. **持久化追蹤機制**：精確追蹤遮罩是否曾經歷手動筆刷編輯，防止上游非破壞性重繪誤覆寫人工心血。
