# InvertImage {: #invertimage }

## 功能概述 {: #what-is-it }

InvertImage 節點藉由反轉所有色彩數值，為輸入影像生成底片負片效果 (Negative Version)。它就像製作傳統攝影負片一樣：暗部區域轉換為亮部，亮部區域轉換為暗部，所有色彩均被反向置換為其互補色 (Complementary Colors)。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 透過反轉影像色彩創造前衛的視覺藝術特效
- 製作極具創意的底片負片風格影像
- 在電腦視覺或影像處理管線中建立高反差邊緣結構
- 在 AI 影像生成工作流程中實驗全新的互補色視覺概念
- 從現有影像快速推導其對比色調盤

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 InvertImage 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 色彩反轉後的負片影像產物將於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

- **input_image**：欲執行色彩反轉的來源影像（可由其他影像節點連線傳入）

### 輸出埠說明 {: #outputs }

- **output**：色彩完全反向後的負片影像產物

## 範例展示 {: #example }

製作照片的藝術負片視覺：

1. 使用 LoadImage 載入照片或使用 GenerateImage 生成畫面
1. 將影像連線至 InvertImage 節點的 "input_image" 參數埠
1. InvertImage 節點將瞬間反向所有 RGB 像素值
1. 將 "output" 引腳連線至 DisplayImage 檢視強烈的負片對比成果

## 重要注意事項 {: #important-notes }

- **RGBA 透明通道完整保護**：對於帶有透明度的 RGBA 影像，節點僅會嚴格反轉 RGB 色彩通道，**原生 Alpha 透明通道將被完整保留**，絕不破壞原有的去背輪廓。
- **色彩模式相容性**：其他特殊色彩模式會先統一轉換為標準 RGB 色彩空間後再執行精確反轉。
- **即時響應運算**：上游影像連線變更時，反轉影像會立即動態重新計算並渲染。
- **無損 PNG 儲存**：產物統一以標準無損 PNG 格式保存。

## 常見問題排解 {: #common-issues }

- **未產生任何輸出**：請檢查 "input_image" 輸入埠是否已正確連線。
- **效果與預期不同**：請記住色彩反轉會產生嚴格的物理互補色（例如藍色變黃色，黑色變白色）。

## 技術實作細節 {: #technical-details }

節點智慧適配不同的影像色彩空間：

- **RGBA 影像**：`RGB_inverted = 255 - RGB`，Alpha 通道原樣複製拼接。
- **RGB 影像**：直接對全通道像素執行 `255 - value` 的數學補數運算。
- **其他格式**：統一映射至 RGB 空間後執行反向。
