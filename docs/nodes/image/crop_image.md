# CropImage {: #cropimage }

## 功能概述 {: #what-is-it }

CropImage 節點提供了對影像裁切 (Cropping)、縮放 (Zooming) 與旋轉 (Rotation) 的精確控制。它允許您擷取影像的特定局部區域、套用數位放大效果，並旋轉校正影像角度，為工作流程構建完美的畫面構圖。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 將影像裁切為指定的像素尺寸或長寬比例 (Aspect Ratio)
- 聚焦凸顯影像中的特定焦點主體
- 套用數位縮放效果以放大局部特寫細節
- 旋轉影像以校正拍攝傾斜的角度
- 在整套工作流程中統一所有素材的尺寸標準
- 剔除影像邊緣無效或多餘的雜物區域
- 依據版面規範預裁切合適的構圖

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 CropImage 節點新增至工作流程中
1. 將影像來源連線至 "input_image" 輸入埠
1. 設定裁切的起點座標 (left, top) 與範圍寬高 (width, height)
1. 視需要調整縮放倍率 (zoom) 與旋轉角度 (rotate)
1. 處理完成的影像將於 "output" 輸出埠傳回

### 參數說明 {: #parameters }

#### 裁切區域設定 (Crop Settings) {: #crop-settings }

- **left**（整數，>= 0，預設值：0）：裁切區域左邊緣相對於原圖的 X 座標像素
- **top**（整數，>= 0，預設值：0）：裁切區域頂邊緣相對於原圖的 Y 座標像素
- **width**（整數，>= 1，預設值：100）：裁切區域的像素寬度
- **height**（整數，>= 1，預設值：100）：裁切區域的像素高度

#### 變形轉換設定 (Transform Settings) {: #transform-settings }

- **zoom**（浮點數，預設值：1.0）：裁切區域的縮放倍率因子

    - 1.0 = 不進行縮放
    - 數值 > 1.0 放大 (Zoom In)
    - 數值 < 1.0 縮小 (Zoom Out)

- **rotate**（角度 Degrees，預設值：0）：影像旋轉的角度數值

    - 正數值表示順時針旋轉
    - 負數值表示逆時針旋轉

### 輸出埠說明 {: #outputs }

- **output**：裁切、縮放與旋轉轉換後的最終完成影像

## 範例展示 {: #example }

典型的影像局部特寫裁切工作流程：

1. 使用 LoadImage 節點載入照片
1. 將該影像連線至 CropImage 節點的 "input_image" 參數埠
1. 定義裁切矩形區域：
    - 將 left 設為 100（從左側第 100 個像素開始）
    - 將 top 設為 50（從頂部第 50 個像素開始）
    - 將 width 設為 400（裁切寬度為 400 像素）
    - 將 height 設為 300（裁切高度為 300 像素）
1. 選配變形效果：
    - 將 zoom 設為 1.2 將裁切畫面數位放大 20%
    - 將 rotate 設為 15 順時針傾斜旋轉 15 度
1. 將 "output" 引腳連線至 DisplayImage 檢視完成的構圖

## 重要注意事項 {: #important-notes }

- **即時預覽 (Live Preview)**：調整座標與旋轉參數時，畫布會即時重新計算並更新展示。
- **邊界智慧檢查 (Boundary Checking)**：節點內部會確保裁切範圍不會越界溢出原始影像畫布。
- **高品質重採樣 (High Quality)**：縮放與旋轉插值採用高品質重採樣濾波演算法（如 Bicubic / Lanczos），最大程度減輕鋸齒與模糊。
- **RGBA 透明度完整保留**：帶有透明通道的 RGBA 影像在裁切與旋轉時將維持 Alpha 透明邊界。

## 常見問題排解 {: #common-issues }

- **裁切區域為空**：請確認 width 與 height 參數值皆大於 0。
- **裁切超出範圍**：請確保 `left + width` 不超過原圖總寬度，且 `top + height` 不超過原圖總高度。

## 技術實作細節 {: #technical-details }

節點執行嚴謹的幾何轉換流水線：

1. **矩形裁切 (Crop)**：從原圖像素陣列中提取指定的座標方塊。
1. **重採樣縮放 (Zoom)**：利用高品質插值對裁切像素塊進行等比縮放。
1. **中心點旋轉 (Rotate)**：以裁切畫面之幾何幾何中心為軸心執行角度矩陣旋轉。
1. **邊界防護 (Boundary Management)**：自動適應邊界像素裁剪與透明填充。
