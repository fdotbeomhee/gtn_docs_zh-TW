# GetListLength {: #getlistlength }

## 功能概述 {: #what-is-it }

GetListLength 節點是一個實用工具節點，專門用於計算並輸出清單中的元素數量。它提供了一種簡潔直接的方法來獲取工作流程中任意清單的長度大小。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 GetListLength 節點：

- 欲確知清單中包含多少個項目
- 欲檢查清單是否為空或是否符合特定數量要求
- 構建依賴於清單大小的分支或迴圈工作流程
- 欲在進一步處理前驗證清單長度
- 欲即時監控動態清單的規模變化

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 GetListLength 節點新增至工作流程中
1. 將任意清單連線至 "items" 輸入埠
1. 節點將自動計算並輸出該清單的長度

### 參數說明 {: #parameters }

- **items**：欲測量長度的目標清單（清單型別輸入）
- **length**：清單中的元素數量（整數輸出）

### 輸出埠說明 {: #outputs }

- **length**：代表輸入清單中項目總數的整數值

## 範例展示 {: #example }

統計待辦任務清單中的任務總數：

1. 將 GetListLength 節點新增至工作流程中
1. 將任務清單連線至 "items" 輸入埠
1. "length" 輸出引腳將顯示該清單中包含的任務總數量

## 重要注意事項 {: #important-notes }

- 當輸入清單發生變動時，節點會自動即時更新計算結果。
- 若輸入清單為空或未連線輸入，長度結果為 `0`。
- 長度輸出始終為非負整數（>= 0）。
- 節點支援包含任意資料型別項目的清單。

## 常見問題排解 {: #common-issues }

- **空清單 (Empty List)**：若未連線清單，長度輸出將為 `0`。
- **無效輸入 (Invalid Input)**：若輸入並非合法清單，長度輸出將為 `0`。
- **型別不匹配 (Type Mismatch)**：本節點專門處理清單輸入，傳入其他非清單型別一律輸出長度 `0`。
