# GetIndexOfItem {: #getindexofitem }

## 功能概述 {: #what-is-it }

GetIndexOfItem 節點是一個定位搜尋工具節點，專門用於在清單陣列中尋找特定元素的出現位置（索引值）。它會傳回該項目在清單中**首次出現**的以 0 為起點之整數索引。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 GetIndexOfItem 節點：

- 欲取得某個具體元素在清單中的精確排序位置
- 欲在集合陣列中定位特定項目
- 流程後續需要根據位置編號精確引用或切換特定元素
- 欲驗證元素是否存在於清單的預期順序中
- 欲在動態變更的清單結構中即時追蹤目標項目的索引走向

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 GetIndexOfItem 節點新增至工作流程中
1. 將清單連線至 "items" 輸入埠
1. 將欲尋找的目標元素連線至 "item" 輸入埠
1. 節點將於輸出端回傳該項目的整數索引位置

### 參數說明 {: #parameters }

- **items**：欲在其中進行搜尋的目標清單（清單型別輸入）
- **item**：欲定位比對的目標元素（可為任意型別）
- **index**：元素在清單中的整數位置輸出

### 輸出埠說明 {: #outputs }

- **index**：代表項目位置的整數值（以 0 為起點；若清單中**不存在該項目則回傳 `-1`**）

## 範例展示 {: #example }

在任務佇列清單中定位特定待辦事項的順序：

1. 將 GetIndexOfItem 節點新增至工作流程中
1. 將現有的任務清單連線至 "items" 輸入埠
1. 將欲定位的任務字串連線至 "item" 輸入埠
1. "index" 輸出引腳將顯示該任務在清單中的具體整數位置（如 `0` 代表排在第一位）

## 重要注意事項 {: #important-notes }

- 若目標元素未出現在清單中，節點一律安全輸出 `-1`。
- 索引計數從 0 開始（第一個元素的索引為 0）。
- 若同一元素在清單中重複出現多次，節點僅會回傳**第一次出現**的索引值。
- 當輸入的清單或比對目標發生變動時，節點會自動即時更新輸出結果。

## 常見問題排解 {: #common-issues }

- **未找到項目 (Item Not Found)**：若目標元素不在清單中，輸出結果必定為 `-1`。
- **缺少輸入連線**：若清單或搜尋目標未正確接線，輸出將為 `-1`。
- **型別不匹配**：搜尋目標的型別需與清單元素具備可比對性（例如字串 `"1"` 與整數 `1` 不會被視為相等）。
- **字串大小寫敏感**：比對文字字串時預設嚴格區分英文大小寫。
