# GetListIsEmpty {: #getlistisempty }

## 功能概述 {: #what-is-it }

GetListIsEmpty 節點是一個實用工具節點，專門用於檢查清單是否為空。它提供布林值 (Boolean) 輸出，指出輸入清單中是否包含任何元素。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 GetListIsEmpty 節點：

- 欲檢查清單中是否含有任何元素項目
- 欲在進一步處理前驗證清單非空
- 依據清單內容狀態構建條件分支工作流程
- 欲確保在執行後續步驟前已有可用資料
- 欲即時監控動態清單的填充狀態

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 GetListIsEmpty 節點新增至工作流程中
1. 將任意清單連線至 "items" 輸入埠
1. 節點將自動進行檢查，並輸出清單是否為空的判定結果

### 參數說明 {: #parameters }

- **items**：欲檢查的目標清單（清單型別輸入）
- **is_empty**：指出清單是否為空的布林值（為空則為 `true`，非空則為 `false`）

### 輸出埠說明 {: #outputs }

- **is_empty**：布林值輸出（若清單為空則為 `true`，若包含元素則為 `false`）

## 範例展示 {: #example }

檢查待辦任務佇列中是否尚有待處理任務：

1. 將 GetListIsEmpty 節點新增至工作流程中
1. 將任務清單連線至 "items" 輸入埠
1. "is_empty" 輸出引腳將在清單中沒有任何任務時輸出 `true`，存在待辦任務時輸出 `false`

## 重要注意事項 {: #important-notes }

- 當輸入清單發生變動時，節點會自動即時更新輸出結果。
- 若未連線任何清單，預設輸出為 `true`（視為空清單）。
- 節點支援檢查包含任意資料型別元素的清單。
- 輸出結果始終為標準布林值。

## 常見問題排解 {: #common-issues }

- **缺少輸入連線 (No Input)**：若未連線任何清單，輸出將為 `true`（為空）。
- **無效輸入 (Invalid Input)**：若傳入的輸入並非合法清單，輸出將為 `true`（為空）。
- **型別不匹配 (Type Mismatch)**：本節點專門處理清單輸入，傳入其他非清單型別一律判定為 `true`（為空）。
