# Get From List {: #get-from-list }

Get From List 節點接收一個清單與一個整數索引值作為輸入，並精準擷取傳回該索引位置上的單一元素。

## 輸入埠 (Inputs) {: #inputs }

- **items** (list)：欲提取元素的目標來源清單
- **index** (int)：欲提取目標元素的整數索引位置（以 0 為起點）

## 輸出埠 (Outputs) {: #outputs }

- **item** (any)：位於清單指定索引處的元素實體。若索引超出範圍或缺少必要輸入，則安全回傳 `None`。

## 運作範例 {: #example }

```python
# 輸入清單: [1, 2, 3, 4, 5]
# 輸入索引: 2
# 產出結果: 3
```

## 注意事項 {: #notes }

- 若索引數值超出清單界限或無效，節點將安全傳回 `None` 而非拋出例外。
- 若缺少清單或索引輸入，節點亦會安全回傳 `None`。
- 輸出引腳型別為 "any"（通用型別），因為清單可容納任意資料型別的實體。
- `index` 參數既可透過引腳連線輸入，亦可於節點屬性面板中手動鍵入固定數值。
