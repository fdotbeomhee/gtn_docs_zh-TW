# CreateList {: #createlist }

## 功能概述 {: #what-is-it }

CreateList 節點是一個通用的清單建立工具節點。它允許您在工作流程中動態建置清單，將多個離散的輸入項目依序聚合為單一清單輸出。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 CreateList 節點：

- 欲將多個離散的獨立項目合併為單一清單
- 欲自工作流程中不同的上游節點輸入建立集合
- 欲建構需要清單規格的資料結構
- 為僅接收清單輸入的下游節點準備前置數據
- 欲將多個變數整合為陣列結構

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 CreateList 節點新增至工作流程中
1. 將個別項目連線至 "items" 輸入埠，或直接在節點屬性面板中手動新增項目
1. 該節點將自動整合所有輸入並輸出單一清單

### 參數說明 {: #parameters }

- **items**：欲整合的項目集合（支援接收任意型別的多重輸入）
- **output**：聚合所有輸入項目後的合併清單

### 輸出埠說明 {: #outputs }

- **output**：包含所有輸入項目的清單物件

## 範例展示 {: #example }

建立包含多元資料型別的複合清單：

1. 將 CreateList 節點新增至工作流程中
1. 將不同的輸入節點連線至 "items" 參數（例如文字、數值或其他物件）
1. 輸出埠將會產出依連線順序排列的完整清單陣列

## 重要注意事項 {: #important-notes }

- CreateList 節點可彈性容納任意資料型別的項目。
- 項目會嚴格依照連線或新增的先後順序依序加入清單中。
- 當任何上游輸入項目的數值發生變更時，節點會自動即時更新輸出結果。
- 支援同時透過引腳連線輸入與屬性面板直接配置兩種方式填充項目。

## 常見問題排解 {: #common-issues }

- **空清單輸出**：若未提供任何輸入項目，輸出將為標準空清單 `[]`。
- **元素型別相容性**：雖然此節點能容納異質型別，但請確保下游接收節點具備相應的型別相容處理能力。
