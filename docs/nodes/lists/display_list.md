# DisplayList {: #displaylist }

## 功能概述 {: #what-is-it }

DisplayList 節點是一個結構展開工具節點，接收一個清單陣列作為輸入，並自動為清單中的每一個元素動態建立獨立的輸出參數引腳。它能自動辨識各元素的底層資料型別，並指派型別相容的輸出埠。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 DisplayList 節點：

- 欲分別獨立存取清單中的特定元素項目
- 欲個別展示或分流處理清單中的每個元素
- 處理包含異質型別的複合清單，需要個別進行型別專屬處理
- 欲將清單內的各個元素分別接駁至流程中不同的下游節點
- 欲更細緻地視覺化拆解與檢視清單資料

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayList 節點新增至工作流程中
1. 將清單連線至 "items" 輸入埠
1. 節點將自動在畫面上為清單內的各項目動態建立專屬輸出埠
1. 視業務邏輯將個別輸出埠連線至其他節點

### 參數說明 {: #parameters }

- **items**：欲展開展示的目標清單（清單型別輸入）
- **item_0, item_1...**：依據清單元素內容動態生成的各項目輸出參數引腳

### 輸出埠說明 {: #outputs }

- **item_0, item_1...**：各清單項目的個別獨立輸出埠，其資料型別自動與該元素實體精確匹配

## 範例展示 {: #example }

將異質清單拆解並分流處理：

1. 將 DisplayList 節點新增至工作流程中
1. 將多元素清單連線至 "items" 輸入埠
1. 節點將自動展開生成對應數量的獨立輸出引腳
1. 依據元素型別分別將其連線至下游相應的處理節點（例如文字連線至 Agent，數值連線至 Math）

## 重要注意事項 {: #important-notes }

- 節點會自動智慧判斷每個元素的資料型別。
- 輸出引腳是根據傳入清單的實際長度動態增減與建立的。
- 支援辨識的原生型別包含：字串 (string)、布林值 (boolean)、整數 (integer)、浮點數 (float) 以及影像產物 (image artifacts)。
- 輸出引腳統一採用循序數字編號命名（`item_0`、`item_1`、`item_2`...）。

## 常見問題排解 {: #common-issues }

- **輸入為空清單**：若傳入為空清單 `[]`，節點將不會產生任何輸出引腳。
- **輸入型別非清單**：若傳入的並非合法清單型別，節點將不產生輸出埠。
- **複雜物件型別降級**：部分高度自訂的特殊複雜物件可能會被寬鬆歸類為 "any" 通用型別。
- **引腳動態變動**：請注意，當上游輸入清單的長度動態變化時，輸出引腳的數量與既有接線可能會連帶重構。
