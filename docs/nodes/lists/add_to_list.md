# AddToList {: #addtolist }

## 功能概述 {: #what-is-it }

AddToList 節點是一個清單操作工具節點，專門用於向既有的清單陣列中新增元素。它允許您彈性指定將新項目插入清單的開頭、末尾或特定索引位置。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 AddToList 節點：

- 欲向既有清單陣列中追加新元素
- 欲在清單的特定位置插入特定資料項
- 欲在工作流程執行過程中動態建構與擴充清單
- 欲維護具備嚴格先後順序的集合結構
- 欲在保留原清單的同時產出擴充後的全新清單

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 AddToList 節點新增至工作流程中
1. 將既有清單連線至 "items" 輸入埠
1. 將欲新增的資料項目連線至 "item" 輸入埠
1. 透過 "position" 參數選擇插入位置
1. 若選用 "index" 位置，請指定具體的整數索引值

### 參數說明 {: #parameters }

- **items**：欲操作的既有目標清單（清單型別輸入）
- **item**：欲新增至清單中的元素項目（可為任意型別）
- **position**：新增位置選項，可選：`"start"` (開頭)、`"end"` (末尾) 或 `"index"` (自訂索引)
- **index**：欲插入的具體整數索引位置（僅在 position 選定為 "index" 時顯示）
- **output**：加入新元素後的產出清單

### 輸出埠說明 {: #outputs }

- **output**：包含原始所有項目並成功注入新元素的擴充清單

## 範例展示 {: #example }

向任務清單末尾追加一項新工作：

1. 將 AddToList 節點新增至工作流程中
1. 將現有的待辦任務清單連線至 "items" 輸入埠
1. 將新的任務文字連線至 "item" 輸入埠
1. 將 "position" 設定為 `"end"`
1. 輸出埠將會產出已在末尾附加新任務的全新完整清單

## 重要注意事項 {: #important-notes }

- 節點會產出一個全新的擴充清單，而非直接在記憶體中修改破壞原始來源清單。
- 當使用 "index" 插入模式時，指定之索引數值必須位於合法範圍之內。
- "index" 欄位僅在 "position" 切換為 "index" 時才會動態顯示。
- 支援任意資料型別的元素，但請留意下游接收節點對清單元素型別的相容要求。

## 常見問題排解 {: #common-issues }

- **索引超出範圍 (Invalid Index)**：若採用 "index" 模式，請確認該數值不超過當前清單的長度上限。
- **輸入為空清單**：若原始輸入為空清單，新元素將自動作為清單的第一個元素。
- **元素型別不符**：留意清單中混合不同資料型別時，下游處理節點是否支援異質陣列。
