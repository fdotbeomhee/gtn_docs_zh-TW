# RemoveFromList {: #removefromlist }

## 功能概述 {: #what-is-it }

RemoveFromList 節點是一個清單操作工具節點，專門用於依據不同準則自現有清單中移除特定項目。它支援透過位置（首項、末項或指定索引值）或透過元素數值比對來移除項目。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 RemoveFromList 節點：

- 欲自現有清單中剔除特定元素
- 欲自集合中過濾掉不符條件的資料項目
- 維護動態清單，並在工作流程執行過程中依需刪除元素
- 欲藉由移除不需要的元素來清理或修訂清單
- 欲精確提取並移除清單中特定位置上的項目

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 RemoveFromList 節點新增至工作流程中
1. 將現有的清單連線至 "items" 輸入埠
1. 透過 "remove_item_by" 參數選定移除項目的方式
1. 根據所選的移除模式，提供相應的索引數值或目標元素
1. 輸出引腳將輸出已完成元素移除的新清單

### 參數說明 {: #parameters }

- **items**：欲自其中移除項目的目標清單（清單型別輸入）
- **remove_item_by**：移除項目的規則選項（可選："first" 首項、"last" 末項、"index" 依索引、"item" 依元素）
- **item**：欲比對移除的特定目標元素（僅於 remove_item_by 設定為 "item" 時顯示）
- **index**：欲移除元素的目標位置索引（僅於 remove_item_by 設定為 "index" 時顯示）
- **output**：移除指定項目後的修訂清單

### 輸出埠說明 {: #outputs }

- **output**：包含原始項目扣除已移除目標後的清單物件

## 範例展示 {: #example }

自任務佇列清單中移除特定已完成的任務：

1. 將 RemoveFromList 節點新增至工作流程中
1. 將任務清單連線至 "items" 輸入埠
1. 將 "remove_item_by" 模式選定為 "item"
1. 將欲移除的任務文字連線至 "item" 輸入埠
1. 輸出埠將會產出已剔除該項任務後的完整清單

## 重要注意事項 {: #important-notes }

- 該節點會建立一份全新清單輸出，不會竄改原始來源清單的結構。
- 當使用 "index"（索引）模式移除時，所傳入的索引值必須在清單的有效邊界範圍內。
- 當使用 "item"（元素）模式移除時，該元素實體必須確實存在於清單中。
- "index" 與 "item" 參數僅會在您選取對應的移除模式時動態顯現於面板中。

## 常見問題排解 {: #common-issues }

- **無效索引 (Invalid Index)**：若採用 "index" 模式，請確保索引值未超出清單範圍。
- **未找到項目 (Item Not Found)**：若採用 "item" 模式，請確認該目標元素確實存在於清單中。
- **空清單 (Empty List)**：若輸入為空清單，將無法執行任何移除動作。
- **型別不匹配 (Type Mismatch)**：使用 "item" 模式時，請確保欲比對之元素型別與清單內元素型別相符。
