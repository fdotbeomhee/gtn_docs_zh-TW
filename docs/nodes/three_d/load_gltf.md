# Load3D {: #load3d }

## 功能簡介 {: #what-is-it }

Load3D 節點是一個能讓您將 GLTF 3D 模型檔案引入工作流程的建構單元。它支援從多種來源載入 3D 模型，以便在專案中加以處理與展示。

## 適用時機 {: #when-would-i-use-it }

在以下情境中適合使用本節點：

- 從實體檔案調用 GLTF 3D 模型
- 將 GLTF 模型傳遞給工作流程中的其他節點
- 在專案中作為 3D 視覺化的一部分進行展示
- 擷取 GLTF 模型的預覽截圖，以作為工作流程中的影像素材

## 操作指南 {: #how-to-use-it }

### 基本設定 {: #basic-setup }

1. 將 Load3D 節點新增至工作流程中。
1. 將其連接至 GLTF 資料來源（檔案瀏覽器選取、網路 URL 或其他節點的輸出端）。

### 參數說明 {: #parameters }

- **gltf**：欲載入的 GLTF 檔案路徑或 URL。可直接連接自其他節點輸出，或透過檔案瀏覽器手動選取。

### 輸出端說明 {: #outputs }

- **gltf**：載入後的 GLTF 產物，可供流程中的其他節點調用。
- **image**：載入之 GLTF 模型的影像快照（在模型載入完成並於介面中儲存快照後提供）。

## 重點注意事項 {: #important-notes }

- 本節點支援透過檔案瀏覽器從本機電腦載入 GLTF 檔案。
- GLTF 模型載入後，您可以利用介面上的「Save Snapshot」（若 UI 有提供）按鈕將當前角度儲存為 2D 影像快照。
- 輸出參數 `image` 僅在明確執行過快照儲存動作後才會釋出產物。

## 常見問題與排解 {: #common-issues }

- **模型未顯示**：請確保已正確連入有效的 GLTF 來源，或已在檔案選取器中指定合法的 3D 檔案。
- **不合法的檔案格式**：請確認您傳入的是標準的 `.gltf` 或 `.glb` 檔案或對應的下載 URL。
- **無法獲取影像輸出**：影像輸出端僅在使用者於 UI 中手動儲存快照後才會產生。請確認是否已觸發該操作。
