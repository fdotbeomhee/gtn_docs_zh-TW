# Search Web {: #search-web }

## 功能概述 {: #what-is-it }

Search Web 工具節點是一個網路搜尋工具，允許您檢索網際網路並從搜尋結果中擷取整合後的文字內容。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 在網際網路上檢索特定主題資訊
- 自搜尋引擎結果頁面中萃取文字資料
- 聚合來自多個外部網站的資料來源
- 執行線上主題調查與深層研究 (Deep Research)

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 Search Web 工具節點新增至工作流程中
1. 將其輸出引腳連線至需要網路搜尋文字結果的下游節點

### 參數說明 {: #parameters }

- **prompt**：欲進行網路檢索的關鍵字查詢字串 (Search Query)
- **summarize**：是否需要大型語言模型 (LLM) 對搜尋到的文字進行智慧摘要
- **search_engine**：欲呼叫的搜尋引擎服務。注意：部分特定搜尋引擎需要配置相應的 API 金鑰

### 輸出埠說明 {: #outputs }

- **output**：自網路搜尋結果中萃取並整合的純文字內容

## 範例展示 {: #example }

檢索特定前沿主題的最新資訊：

1. 將 Search Web 工具節點新增至工作流程中
1. 設定搜尋查詢關鍵字
1. 將 "output" 引腳連線至需要搜尋結果的另一個節點（如 Agent 節點）
1. 該工具將傳回整理完備的搜尋文字結果

## 實作細節 {: #implementation-details }

Search Web 工具利用強大的網路搜尋介面尋找高度相關的公開網頁，並自動萃取網頁正文核心內容。它旨在協助您以結構化、可靠的方式自動化蒐集網路資料。
