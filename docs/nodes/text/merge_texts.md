# MergeTexts {: #mergetexts }

## 功能概述 {: #what-is-it }

MergeTexts 節點是一個文字合併工具節點，專門用於將多個獨立文字字串整合為單一純文字輸出。它允許您使用可自訂的分隔字元 (Separator) 串接不同的文字片段。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 MergeTexts 節點：

- 欲整合來自多個來源或不同上游節點的文字
- 欲以一致的排版格式串接獨立文字片段
- 構建由多個元件聚合內容的文案生成工作流程
- 欲將各自獨立的章節區塊拼接成完整文件

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 MergeTexts 節點新增至工作流程中
1. 將其他節點的多個文字輸出引腳連線至本節點的輸入埠
1. 視需要配置自訂的分隔字串 (merge_string)
1. 將輸出埠連線至需要合併文字的下游節點

### 參數說明 {: #parameters }

- **input_1 至 input_4**：固定數量的文字輸入埠（最多支援 4 個輸入）
- **merge_string**：插入於各文字段落之間的分隔字串（當 trim_whitespace 設為 False 時預設為 `\n\n`）
- **whitespace**：布林選項，用以決定是否去除各輸入文字前後的空白字元 (Trim) 以及最終結果的修剪

### 輸出埠說明 {: #outputs }

- **output**：整合拼接後的完整單一文字字串

## 範例展示 {: #example }

將獨立章節拼接為一篇完整報告：

1. 將 MergeTexts 節點新增至工作流程中
1. 連線三個不同文字節點的輸出（例如標題 title、內文 body、結論 conclusion）
1. 將 merge_string 參數設為 `\n\n` 以保留段落空行間距
1. 輸出埠將會產出以該分隔字元串接完成的完整文件文字

## 重要注意事項 {: #important-notes }

- 當啟用 `whitespace`（修剪模式）時，每個輸入文字在串接前皆會先清除頭尾空白。
- 當啟用 `whitespace` 且分隔字元為空時，各段文字將直接緊密拼接。
- 當停用 `whitespace` 時，空字串輸入會被自動過濾，且若未特別指定則分隔符預設為 `\n\n`。
- 分隔字元僅會插入於相鄰段落之間，不會附加於開頭或末尾。
- **使用建議**：若需要動態數量更靈活的文字串接能力，建議參考使用 **JoinText** 節點。

## 常見問題排解 {: #common-issues }

- **非預期的排版格式**：請檢查您的 merge_string 是否包含正確的換行符或空白。
- **內容缺失遺漏**：請確認所有預期的上游文字連線皆已正確接駁至輸入埠。
