# TextInput {: #textinput }

## 功能概述 {: #what-is-it }

TextInput 節點提供了一種簡潔直接的方式，用於在工作流程中輸入並定義各類文字內容。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 TextInput 節點：

- 欲建立自訂文字內容
- 欲為工作流程中的其他節點準備前置文字輸入
- 定義系統提示詞 (Prompts)、操作指令或多段落結構化文字
- 構建需要結構化文字輸入的工作流程

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 TextInput 節點新增至工作流程中
1. 於 "text" 參數中輸入您所需的多行文字內容
1. 將輸出埠連線至接收文字輸入的下游節點

### 參數說明 {: #parameters }

- **text**：多行文字內容（字串型別，預設為空字串）

### 輸出埠說明 {: #outputs }

- **text**：輸出為字串格式的多行文字內容

## 範例展示 {: #example }

為 AI 助手建立結構化提示詞 (Prompt)：

1. 將 TextInput 節點新增至工作流程中

1. 將 "text" 參數設定為：

    ```
    您是一位專業熱忱的在地旅遊導遊助手。
    請針對以下景點提供詳細資訊：
    - 該地的歷史背景
    - 主要推薦景點
    - 最佳旅遊季節
    - 在地特色美食
    ```

1. 將輸出埠連線至 Agent 節點的 prompt 參數引腳

## 重要注意事項 {: #important-notes }

- 輸出內容中會完整保留所有的換行符號 (Line Breaks)。
- 節點支援任何合法的字串文字內容。
- 空字串屬於合法輸入，節點將相應輸出空字串。
- 本節點無硬性字元上限限制，但處理極其龐大的超長文字區塊時可能會對運行效能產生影響。

## 常見問題排解 {: #common-issues }

- **文字編碼與格式異常**：自不同外部來源複製貼上文字時，請留意並清除不可見的特殊控制字元。
- **跨平台換行相容性**：不同作業系統環境對換行符（CRLF vs LF）的渲染可能有些微差異。
