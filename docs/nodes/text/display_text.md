# DisplayText {: #displaytext }

## 功能概述 {: #what-is-it }

DisplayText 節點用於在工作流程畫布中直接視覺化展示文字內容，並可作為直通傳遞節點。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用 DisplayText 節點：

- 欲在工作流程中直觀檢視執行結果或即時資訊
- 欲展示上游處理步驟所輸出的文字結果
- 作為執行過程中動態更新文字內容的視覺化佔位節點
- 在工作流程圖中建立具備高可讀性的文字標籤或說明
- 欲在流程特定節點處即時視覺化檢視字串數據

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 DisplayText 節點新增至工作流程中
1. 視需求於屬性面板中輸入初始文字數值
1. 將上游輸出連線至 "text" 參數埠，或手動鍵入文字
1. 視需要將 "text" 輸出埠連線至其他需要文字輸入的下游節點

### 參數說明 {: #parameters }

- **text**：欲展示的文字內容（字串輸入，支援多行文字）

### 輸出埠說明 {: #outputs }

- **text**：原樣輸出的相同文字內容，可供連線至其他下游節點

## 範例展示 {: #example }

檢視 AI Agent 代理節點生成的文字結果：

1. 將 DisplayText 節點新增至工作流程中
1. 將 Agent 節點的輸出引腳連線至 DisplayText 節點的 "text" 輸入參數埠
1. 當工作流程執行時，AI 生成的最新文字將動態呈現在 DisplayText 節點的面板中

## 重要注意事項 {: #important-notes }

- DisplayText 節點主要用於視覺化展示，不會竄改任何文字內容。
- 該節點原汁原味地直通傳遞所接收到的文字，不施加任何額外的後製處理或格式變更。
