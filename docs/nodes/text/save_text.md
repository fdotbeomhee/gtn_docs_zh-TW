# SaveText {: #savetext }

## 功能概述 {: #what-is-it }

SaveText 是一個檔案儲存工具節點，允許您將文字內容直接寫入本機檔案系統中的檔案。本節點提供簡潔直觀的介面，透過可自訂的輸出路徑將文字資料持久化寫入磁碟。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 欲將 AI 生成的文字內容儲存至檔案
- 欲將工作流程執行結果匯出為文字檔
- 保存對話日誌或輸出資料供日後查閱
- 作為自動化工作流程的一環自動建立文字檔案
- 在工作流程多次執行之間持久化保存資料

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 SaveText 節點新增至工作流程中
1. 將上游文字來源連線至 "text" 輸入埠，或直接在節點中手動鍵入文字
1. 指定輸出檔案路徑，或直接沿用預設路徑
1. 執行工作流程以將文字寫入指定的本機檔案中

### 參數說明 {: #parameters }

- **text**：欲儲存至檔案的文字內容（支援多行文字）
- **output_path**：儲存目標檔案的本機路徑（預設為 `"griptape_output.txt"`）

### 輸出埠說明 {: #outputs }

- **output_path**：已儲存檔案的路徑字串（確認儲存作業成功完成）

## 範例展示 {: #example }

將 AI Agent 生成的回應儲存至文字檔案中：

1. 將 Agent 節點新增至工作流程中
1. 設定 Agent 的提示詞以生成特定文字
1. 新增 SaveText 節點至工作流程
1. 將 Agent 節點的 "output" 輸出引腳連線至 SaveText 節點的 "text" 輸入埠
1. 將 "output_path" 設定為 `"my_agent_response.txt"`
1. 執行工作流程
1. Agent 的回應內容將自動儲存至本機磁碟的 `"my_agent_response.txt"` 檔案中

## 重要注意事項 {: #important-notes }

- 若目標檔案尚不存在，節點會自動建立；若已存在，**將直接覆寫原有內容**。
- 屬性面板中的 output_path 參數附帶檔案選擇儲存按鈕，便於直觀瀏覽目錄選取位置。
- 支援使用相對路徑或絕對路徑指定輸出檔案。
- 若目標路徑的上層目錄不存在，節點會自動遞迴建立所需的父層目錄。
- 文字檔案統一採用 UTF-8 編碼格式進行寫入。

## 常見問題排解 {: #common-issues }

- **權限不足 (Permission Errors)**：請確保目前環境對目標儲存目錄具備檔案寫入權限。
- **路徑無效 (Invalid Path)**：請確認所輸入的路徑格式符合目前作業系統的規範。
- **檔案覆寫注意 (File Already Exists)**：請特別留意，若目標檔案已存在將直接覆寫且不發出提示確認。
