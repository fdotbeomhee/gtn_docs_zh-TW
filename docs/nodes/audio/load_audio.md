# LoadAudio {: #loadaudio }

## 功能簡介 {: #what-is-it }

LoadAudio 節點是一個簡潔基礎的建構單元，讓您能將音訊檔案載入至工作流程中。您可以將其視為選取一段錄音檔，以便在專案中加以調用。

## 適用時機 {: #when-would-i-use-it }

在以下情境中適合使用本節點：

- 調用由其他節點生成的音訊檔案
- 將音訊檔案傳遞給工作流程中的後續節點
- 將音訊檔案作為專案管線的一部分進行處理

## 操作指南 {: #how-to-use-it }

### 基本設定 {: #basic-setup }

1. 將 LoadAudio 節點新增至工作流程中。
1. 將其連接至音訊來源（例如 Transcribe Audio 節點或檔案來源）。

### 參數說明 {: #parameters }

- **audio**：欲載入的音訊（可直接連線自其他節點的音訊輸出端）。

### 輸出端說明 {: #outputs }

- **audio**：載入後的音訊產物，可供流程中的其他節點直接調用。

## 範例示範 {: #example }

假設您在電腦中保存了一段預先錄製的音訊，並希望在其他節點中使用：

1. 建立一個 LoadAudio 節點。
1. 點擊載入音訊按鈕，從磁碟中選取您的音訊檔案。
1. LoadAudio 節點便會將該音訊釋出，供後續工作流程繼續運算。

## 重點注意事項 {: #important-notes }

- LoadAudio 節點純粹負責傳遞音訊——它不會對音訊內容本身進行任何修改或破壞性變更。
- 您可以點擊檔案瀏覽器圖示，從本機電腦中選取音訊檔案。
- 點擊播放按鈕即可直接在介面中試聽該音訊。
