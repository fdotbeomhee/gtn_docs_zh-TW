# Microphone {: #microphone }

## 功能簡介 {: #what-is-it }

Microphone 節點讓您能直接從電腦的麥克風錄製音訊。這是在工作流程中擷取即時語音輸入的最直覺方式。

## 適用時機 {: #when-would-i-use-it }

在以下情境中適合使用本節點：

- 直接從麥克風錄製即時音訊
- 擷取語音輸入以供後續文字轉錄 (Transcription)
- 建立錄音作為專案管線的一部分
- 為工作流程中的其他節點提供即時音訊輸入

## 操作指南 {: #how-to-use-it }

### 基本設定 {: #basic-setup }

1. 將 Microphone 節點新增至工作流程中。
1. 點擊麥克風圖示開始錄音。
1. 對著麥克風說話或輸入環境聲音。
1. 結束錄音時點擊停止按鈕。

### 參數說明 {: #parameters }

- **audio**：錄製完成的音訊輸出端（型別為 `AudioUrlArtifact`）。

### 輸出端說明 {: #outputs }

- **audio**：錄製完成的音訊產物，可供流程中的其他節點直接調用。

## 範例示範 {: #example }

錄製音訊並進行語音轉文字的典型工作流程：

1. 在工作流程中新增一個 Microphone 節點。
1. 錄製您的語音輸入。
1. 將 "audio" 輸出端連接至 TranscribeAudio 節點的音訊輸入端。
1. 轉錄完成的文字內容即可在 TranscribeAudio 節點的輸出端中獲取。

## 重點注意事項 {: #important-notes }

- 本節點需要在瀏覽器中授予麥克風存取權限。
- 音訊採即時即錄方式擷取。
- 錄音品質取決於您的硬體麥克風規格與作業系統音訊配置。
- 無論瀏覽器採用何種格式錄音，音訊資料都會被妥善存檔並包裝為 `AudioUrlArtifact` 產物輸出。

## 常見問題與排解 {: #common-issues }

- **無法存取麥克風**：請確保瀏覽器已取得系統的麥克風存取授權。
- **音訊品質不佳**：請檢查作業系統中的麥克風輸入音量與音訊裝置配置。
- **無法開始錄音**：請確認目前沒有其他應用程式獨佔鎖定該麥克風裝置。
