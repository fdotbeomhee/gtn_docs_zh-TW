# Dictionary {: #dictionary }

## 功能概述 {: #what-is-it }

Dictionary 節點讓您能透過分別提供鍵名清單 (Keys) 與數值清單 (Values) 來建立一個字典（鍵值對集合，Key-Value Pairs）。這是在工作流程中組織關聯性資料並賦予名稱的最直觀方式。

## 適用情境 {: #when-would-i-use-it }

在以下情況使用此節點：

- 欲透過具名鍵值組織相互關聯的業務數據
- 欲建立結構化物件並傳遞給工作流程中的其他節點
- 欲為其他元件或驅動組合配置設定集合
- 欲以易於依鍵名檢索的格式整理資料
- 欲將多個離散的變數整合為單一結構化實體

## 使用方式說明 {: #how-to-use-it }

### 基礎設定步驟 {: #basic-setup }

1. 將 Dictionary 節點新增至工作流程中
1. 分別設定鍵名清單與數值清單
1. 將輸出的字典物件連線至需要結構化數據的下游節點

### 參數說明 {: #parameters }

- **keys**：字串清單，作為字典中的鍵名 (Keys)
- **values**：數值清單（字串、數值、布林值或子陣列），與各個鍵名依序對應

### 輸出埠說明 {: #outputs }

- **dict**：組裝完成的字典物件，包含所有映射之鍵值對

## 範例展示 {: #example }

為使用者設定檔建立組態字典：

1. 將 Dictionary 節點新增至工作流程中
1. 將 "keys" 參數設定為：
    ```
    ["name", "age", "premium_member", "interests"]
    ```
1. 將 "values" 參數設定為：
    ```
    ["Jane Smith", 32, true, ["hiking", "photography", "coding"]]
    ```
1. 產出的輸出字典將為：
    ```
    {"name": "Jane Smith", "age": 32, "premium_member": true, "interests": ["hiking", "photography", "coding"]}
    ```
1. 將此字典連線至流程中需要讀取使用者檔案資訊的下游節點

## 重要注意事項 {: #important-notes }

- 所有鍵名皆會自動強制轉換為字串型別。
- 若鍵名清單長度大於數值清單，多出的鍵名將會自動指派為 `None`。
- 空白或為 `None` 的鍵名原則上會被忽略略過。
- 若傳入單一值而非陣列清單，節點會自動將其包裝為單元素清單處理。
- 支援豐富的數值型別，包含字串、浮點數、整數、布林值以及巢狀清單。

## 常見問題排解 {: #common-issues }

- **清單長度不匹配 (Mismatched Lists)**：若鍵名清單與數值清單長度不一，多出的鍵會被填入 `None`，或多出的數值會被略過。
- **鍵名字串轉換**：複雜物件若傳入鍵名皆會被強制轉為字串表示。
- **空白鍵名略過**：若鍵名為空字串或 `None`，該項目可能不會被寫入最終字典中。
